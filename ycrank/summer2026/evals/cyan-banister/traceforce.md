# Traceforce -- Cyan Banister Evaluation

Move the clock to 2032. Enterprise AI agents routinely operate local files, credentials, developer tools, and MCP servers without waiting for a human to approve every step. Security teams cannot govern that world from a network gateway because the consequential action happens on the device. Traceforce has found a real leak from that future: its software already observes more than 1,500 devices across five enterprises, while its Atlas registry catalogs over 600 MCPs. The future chain is incomplete—the dossier does not explain how endpoint enforcement becomes the durable control plane—but this is more than a fashionable market forecast.

The founders know the machinery they are touching. Xia Hua led Clumio’s flagship data-protection products and holds cloud-security patents; Varun Wadhwa built distributed backup infrastructure and RAG database systems. They worked together before starting Traceforce, interviewed more than 50 CISOs and CIOs, and then produced MCP X-Ray, TraceGraph, and a deployable endpoint agent. That is credible Rizz, Tizz, and Biz evidence, although I cannot find the dated pre-company obsession or independently built artifact that would establish either founder as a first believer before agent security became crowded.

The strongest fact is not the 80 GitHub stars. It is that five enterprises accepted software that inventories AI applications and records prompts and tool calls across employee devices. One deployment covers a company with more than 500 employees, and Fortune 500 companies are running proofs of concept. Installing endpoint security creates operational burden, employee scrutiny, and false-positive risk; doing it across 1,500 devices is costly behavior. Revenue is undisclosed, but at pre-seed this deployment footprint is more informative than a small MRR number.

Now the uncomfortable part: Traceforce protects agency more clearly than it returns agency. The broken mechanism is precise—gateways cannot observe local agent execution—but the dossier does not identify an artificial rent, institutional beneficiary, or person gaining new occupational control. Worse, recording prompts, reasoning, tool calls, and outcomes creates exactly the sensitive activity repository I investigate before signing. SOC 2 and ISO 27001 establish process discipline, not a limiting architecture for consent, custody, retention, or administrator abuse.

The bull case says endpoint AI security is becoming a necessary enabling layer, and Traceforce’s early device coverage lets it accumulate the activity graph before larger vendors understand the new execution surface. The bear case stings harder: Zenity already advertises endpoint discovery and pre-execution blocking, WitnessAI controls MCP activity at the network layer, and Noma covers posture, red teaming, and runtime protection. Without published enforcement accuracy, retention, or a structurally unique data asset, TraceGraph may become a feature inside an endpoint suite. My 36-month base case is that CrowdStrike acquires Traceforce before it reaches $10 million ARR to add AI-agent telemetry to its endpoint platform.

I am neutral, narrowly below a check. There is a working artifact, unusually meaningful deployment behavior, and a sensible position beneath the visible AI wave. But today I see a valuable security module more readily than a defining independent company, and the surveillance architecture remains unresolved. One verifiable condition would flip me: a third-party data-flow audit proving that raw prompts, credentials, and file contents remain on-device and cannot be centrally reconstructed.
