## The Idea

- **Problem** Engineering teams running coding agents across tools and machines manually relay context between sessions, and agents can repeat investigations or make conflicting changes ([Launch YC](https://www.ycombinator.com/launches/XFb-opencrawl-multiplayer-for-your-coding-agents)).
- **Approach** OpenCrawl captures full agent sessions for search through MCP and offers a shared board where supported agents post updates, subscribe to topics, and receive mentions across local and cloud environments ([OpenCrawl GitHub](https://github.com/getopencrawl/opencrawl-core)).
- **Differentiation** OpenCrawl defaults captured sessions to team visibility and combines searchable transcripts with a shared board, while Agent Relay lets users choose what to share, Entire attaches agent transcripts to Git history, and Mem0 exposes memory through an application API ([OpenCrawl capture docs](https://github.com/getopencrawl/opencrawl-core/blob/main/docs/capture-privacy.md), [Agent Relay](https://agentrelay.com/), [Entire](https://entire.com/news/entire-launches-distributed-git-network-for-the-agent-era), [Mem0](https://mem0.ai/series-a)).
- **Business Model** Hosted usage includes 100M ingestion tokens free monthly per team and 200M for YC companies, with no card required, and AI Tool Index reports $0.50 per additional million tokens ([Launch YC](https://www.ycombinator.com/launches/XFb-opencrawl-multiplayer-for-your-coding-agents), [YC company profile](https://www.ycombinator.com/companies/opencrawl), [AI Tool Index, Nov 2026](https://aitoolindex.org/tool/opencrawl/)). Website not accessible at time of research.
- **TAM/SAM** No public TAM/SAM data found for this specific segment.
- **GTM / Distribution** OpenCrawl launched through YC and the CEO’s X account, with self-serve cloud access, a YC-specific free allowance, and public self-hosting instructions ([Launch YC](https://www.ycombinator.com/launches/XFb-opencrawl-multiplayer-for-your-coding-agents), [YC company profile](https://www.ycombinator.com/companies/opencrawl), [Doomers AI](https://doomers.ai/launches/opencrawl), [OpenCrawl GitHub](https://github.com/getopencrawl/opencrawl-core)).

## Defensibility

- **Moat today** No defensibility signals found in public sources.
- **Future moat** [Inferred]: A team’s accumulated, searchable decision history could make switching more work, and public retention and migration data would be needed to establish the effect ([OpenCrawl GitHub](https://github.com/getopencrawl/opencrawl-core)).
- **Market structure** No structural barrier identified at this stage.
- **Commoditization risk** Anthropic already ships shared task lists and direct messaging for Claude Code sessions, and Agent Relay already offers cross-tool messaging and searchable session history ([Claude Code docs](https://code.claude.com/docs/en/agent-teams), [Agent Relay YC profile](https://www.ycombinator.com/companies/agent-relay)).

## Key Risks

- **Transcript exposure** Captured sessions are team-visible by default and masking can miss some secrets, with opt-in capture, project and session exclusions, private sessions, and self-hosting available as controls ([OpenCrawl capture docs](https://github.com/getopencrawl/opencrawl-core/blob/main/docs/capture-privacy.md), [OpenCrawl GitHub](https://github.com/getopencrawl/opencrawl-core)).
- **Native substitution** [Inferred]: Claude Code’s messaging and shared tasks could cover coordination for teams using that tool alone, while OpenCrawl supports cross-tool search for teams using multiple clients ([Claude Code docs](https://code.claude.com/docs/en/agent-teams), [OpenCrawl GitHub](https://github.com/getopencrawl/opencrawl-core)).
- **Technical feasibility across clients** Other MCP clients can search, while push mentions require a supported listener, so mixed-tool teams can have uneven access to live coordination ([OpenCrawl GitHub](https://github.com/getopencrawl/opencrawl-core)).
- **Name collision** [Inferred]: The unrelated `janhq/OpenCrawl` web crawler shares the product name, which can cause confusion in search and repository discovery ([Jan GitHub](https://github.com/janhq/OpenCrawl), [OpenCrawl GitHub](https://github.com/getopencrawl/opencrawl-core)).
