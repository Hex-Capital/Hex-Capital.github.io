# Almanac -- Peter Thiel Evaluation

743 GitHub stars and five displayed engineering-team users make **Almanac** a thesis-bearing developer tool, not merely an “AI for X” wrapper. **Almanac** is strongest on the contrarian secret and weakest on structural moat: repository-owned Markdown and locally indexed agent conversations identify a real blind spot in Cognition’s hosted DeepWiki, but the insight lives entirely in copyable software. The secret may be right while the business remains wrong. A truth without durable ownership becomes someone else’s feature.

**Stripe** is the high rung because developer-first payments exploited an architectural and cultural failure that legacy processors could not repair without rebuilding themselves. **Almanac** shares the mechanism at smaller scale: DeepWiki hosts repository knowledge, whereas Almanac places Git-reviewable memory inside the repository and ingests Codex and Claude Code sessions. **Almanac** diverges where the analogy becomes load-bearing—Cognition controls Devin’s conversations and repository interface, has more than $1 billion raised, and can implement local or reviewable memory without destroying its economics. The named incumbent exists; the named blind spot exists. The five-year reason the incumbent must remain blind does not.

**Asana** is the low rung on atoms and regulation: pure workflow software had no capex, certification, or government-customer barrier, and only Dustin Moskovitz’s Facebook pedigree justified the exception. **Almanac** reproduces that structural weakness more completely. Almanac’s Apache-2.0 CLI, repository-local Markdown, and local indexing improve privacy but create no regulated moat; 68 forks demonstrate that the product can propagate without proprietary control. “We wanted flying cars, instead we got 140 characters” was a complaint about precisely this abundance of imitable bits.

Cognition’s DeepWiki, Swimm, Mintlify, and Greptile create an 18-month monopoly test for **Almanac**. Each additional Almanac installation could generate a valuable corpus connecting conversations, code changes, incidents, and accepted documentation edits, but Almanac has published neither a proprietary dataset nor a measured retrieval advantage. Without shared learning, repository-local deployment fragments the corpus rather than compounding it. Almanac’s moat then shrinks as adoption grows: more GitHub stars teach competitors that the feature matters while Apache-2.0 gives them the implementation vocabulary. Competition is for losers because competitors convert product insight into commodity pricing.

Version 0.1.5 and a daily “garden” process show that **Almanac** has made an architectural commitment—persistent Markdown reviewed through Git—but not a definite multi-year plan. **Almanac** would move up a tier if Kushagra Chitkara named irreversible milestones such as cross-agent provenance, benchmarked retrieval accuracy, enterprise policy enforcement, and a three-year route to becoming the canonical record for agent decisions. The dossier instead supplies macOS support, Python 3.12+, and future hosted integrations. Those are releases, not destiny. Definite optimism requires a map longer than the next customer conversation.

Rohan Sharma’s research at the Vector Institute, CMU, and MIT gives **Almanac** genuine technical credibility, but **Quora** is the relevant single-anchor parallel: Adam D’Angelo’s Facebook CTO history overrode an indefinite roadmap and contested network moat. **Almanac** has no comparable override. Kushagra Chitkara has Harvard and IIT credentials, Divit Sheth was a senior engineer at Arcesium, and the repository records 843 commits; none has publicly shipped a product to scale. Almanac passes the competence test and fails the revealed-lineage test—the unstated PayPal-Mafia pattern is absent, not merely undocumented.

Five displayed engineering teams and 743 stars lead to a specific forecast: by July 2029, **Cognition acquires Almanac for less than $50 million before Almanac reaches $5 million ARR, then folds repository-local agent memory into Devin**. Almanac has identified a useful control layer at exactly the point where the platform owner has both the distribution and the substitution incentive. The highest-secret, lowest-structural-moat signature usually produces a feature acquisition, not an independent monopoly.

843 commits, 68 forks, and five early users form the strongest bull case for **Almanac**: open-source distribution could establish repository Markdown as a neutral standard across Codex, Claude Code, and Devin, while privacy-sensitive enterprises reject vendor-owned memory. The known-exception argument is **Asana**—pure software can win when an apparently ordinary workflow becomes the system of record. The objection stings, but Almanac lacks Asana’s operator-pedigree override, has no published revenue, and depends on interfaces controlled by coding-agent vendors. I pass. A verifiable $5 million ARR run rate with at least half of usage spanning two or more agent vendors would flip the verdict by proving Almanac owns the neutral layer rather than renting access to it.
