## The Idea

- **Problem:** Gamers and users of computer agents who want hands-free input generally use keyboards or mice, while EEG control has largely required lab equipment and individual setup ([Launch YC](https://www.ycombinator.com/launches/WdW-dydema-personal-programmable-brain-computer-interfaces), Oct 2026).
- **Approach:** A scalp EEG cap feeds a decoder that recognizes a user's imagined movements after a short calibration and binds each recognized command to an action such as a keystroke or agent instruction ([Dydema](https://dydema.com/), [Launch YC](https://www.ycombinator.com/launches/WdW-dydema-personal-programmable-brain-computer-interfaces)).
- **Differentiation:** Dydema reports calibrating a pretrained decoder on new users, while EmotivBCI and Neurosity Kinesis document training individual commands, OpenBCI Galea targets multimodal research, and Neurable One measures focus through EEG headphones ([Launch YC](https://www.ycombinator.com/launches/WdW-dydema-personal-programmable-brain-computer-interfaces), [EmotivBCI](https://www.emotiv.com/emotiv-bci), [Neurosity SDK](https://docs.neurosity.co/docs/api/kinesis/), [OpenBCI Galea](https://galea.co/discovery-program), [Neurable One](https://www.neurable.com/products/neurable-one)).
- **Business Model:** The earlier Wizard research API charges $1 to fit a classifier, $1 per model per month to host it, and $0.003 per prediction window, with free test keys and $5 in starting credit ([Dydema API Pricing](https://developers.dydema.com/pricing), effective Sep 23, 2026).
- **TAM/SAM:** BCC Research projected $187.2M in global entertainment and gaming BCI sales for 2026 at 13.5% CAGR from 2021 to 2026, an adjacent-market estimate that covers gaming and entertainment applications ([BCC Research](https://staging.bccresearch.com/public/RedactedRO/IAS180A.pdf)).
- **GTM / Distribution:** Dydema offers self-serve API keys, solicits integrations from game, agent, and robotics developers, and describes online ordering as its plan for the consumer headset ([Dydema API](https://developers.dydema.com/), [Launch YC](https://www.ycombinator.com/launches/WdW-dydema-personal-programmable-brain-computer-interfaces)).

## Defensibility

- **Moat today:** Dydema reports cleaning and standardizing approximately 128,000 hours of existing EEG recordings and says its pretrained decoder outperformed models trained on each user's own data in internal benchmarks ([Launch YC](https://www.ycombinator.com/launches/WdW-dydema-personal-programmable-brain-computer-interfaces), Oct 2026).
- **Future moat:** [Inferred]: Exclusive recordings collected during everyday use could improve decoding outside the lab, with the advantage contingent on collection scale and measured gains on the consumer headset ([Dydema](https://dydema.com/)).
- **Market structure:** No structural barrier identified at this stage.
- **Commoditization risk:** Emotiv and Neurosity already offer programmable EEG commands, and Wizard can select licensed pretrained models, giving competitors existing hardware and model components to build on ([EmotivBCI](https://www.emotiv.com/emotiv-bci), [Neurosity SDK](https://docs.neurosity.co/docs/api/kinesis/), [Dydema API](https://developers.dydema.com/)).

## Key Risks

- **Consumer headset performance:** The prototype uses a research cap and recognizes a small set of commands, while Dydema is training models for cheaper sensors and working to increase command count and decoding speed ([Dydema](https://dydema.com/), [Launch YC](https://www.ycombinator.com/launches/WdW-dydema-personal-programmable-brain-computer-interfaces)).
- **Input substitution:** [Inferred]: Calibration and a limited command set constrain replacement of keyboards and mice, with Dydema demonstrating discrete actions such as confirming an agent prompt as an initial use case ([Dydema](https://dydema.com/), [Dydema Media](https://dydema.com/media)).
- **Neural-data handling:** California classifies neural data as sensitive personal information, and Dydema's research API terms allow model-improvement use of submitted and derived data while offering on-premises licensing to labs that cannot upload recordings ([California Privacy Protection Agency](https://cppa.ca.gov/meetings/materials/20250501_item3_sb44.pdf), [Dydema API Terms](https://developers.dydema.com/terms)).
