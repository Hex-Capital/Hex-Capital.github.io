## The Idea

- **Problem:** Engineering teams operating multiple coding agents across separate sessions lose decision history and must manually reconstruct context when colleagues take over ([Mosaic website](https://mosaic.inc), Aug 2026).
- **Approach:** Mosaic provides a persistent shared environment where people see one another’s agents working, jointly control terminals, preserve session state, and connect agents across devices ([Mosaic website](https://mosaic.inc), Aug 2026).
- **Differentiation:** Conductor and Superset primarily orchestrate parallel agents in isolated workspaces, while Pentagon organizes autonomous agent teams, whereas Mosaic exposes real-time shared terminal control to multiple humans and agents ([Oflight](https://www.oflight.co.jp/en/columns/tag/Mosaic), Jul 2026; [Superset documentation](https://docs.superset.sh/agent-integration), 2026; [Pentagon YC page](https://www.ycombinator.com/companies/pentagon), 2026).
- **Business Model:** The Hobby tier is free, while Team costs $200 per seat per month for up to 20 seats and includes direct teammate access plus a two-week cancellation and money-back guarantee ([Mosaic pricing](https://mosaic.inc/pricing), Aug 2026).
- **TAM/SAM:** The global AI-code-tools market was estimated at $29.47B in 2025 with 17.52% projected CAGR through 2032, while the multi-agent-systems segment was estimated at $7.71B in 2025 with 45.3% projected CAGR through 2033 ([Research and Markets](https://www.researchandmarkets.com/report/ai-code-tools), 2026; [Grand View Research](https://www.grandviewresearch.com/industry-analysis/multiagent-systems-market-report), 2026).
- **GTM / Distribution:** [Inferred]: The free Hobby tier, downloadable macOS client, public demos, and paid Team tier indicate developer-led adoption followed by per-seat conversion and demo-led team sales ([Mosaic website](https://mosaic.inc); [Mosaic pricing](https://mosaic.inc/pricing), Aug 2026).

## Key Risks

- **Competitive convergence:** Superset is developing collaborative agent orchestration, while Pentagon already advertises persistent memory and human multiplayer, narrowing Mosaic’s public feature distinction ([Superset](https://www.ycombinator.com/companies/superset); [Pentagon](https://www.ycombinator.com/companies/pentagon), 2026).
- **Agent security boundaries:** Mosaic connects agents to shared terminals, apps, and external-agent networks, while Anthropic documented Claude Code vulnerabilities and a controlled prompt-based credential-exfiltration test that succeeded in 24 of 25 attempts; Mosaic states that partner networking is encrypted and policy-verified but publishes no security architecture ([Mosaic website](https://mosaic.inc); [Anthropic](https://www.anthropic.com/engineering/how-we-contain-claude), Jun 2026).
- **Platform dependency:** Mosaic operates Claude Code, Codex, and OpenCode sessions, so upstream CLI, authentication, pricing, or permission changes can affect compatibility ([Oflight](https://www.oflight.co.jp/en/columns/tag/Mosaic), Jul 2026).
- **Product-positioning ambiguity:** The public site markets Mosaic as the shared environment while separately linking to Ocean, without a public transition timeline or separate Ocean feature documentation ([Mosaic website](https://mosaic.inc), Aug 2026).
- **Name collision:** YC separately lists a Winter 2025 video-agent company named Mosaic, and Product Hunt results for “Mosaic” resolve to that company, creating search and attribution ambiguity; the mosaic.inc domain and @mosaic_ide handle provide disambiguation ([YC](https://www.ycombinator.com/companies/mosaic-2); [Product Hunt](https://www.producthunt.com/products/mosaic-so), 2026).
