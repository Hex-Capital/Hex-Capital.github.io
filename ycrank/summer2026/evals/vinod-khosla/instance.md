# Instance -- Vinod Khosla Evaluation

Claire Mao and Lucy Cai moved Instance from an AI data analyst in February 2026 to robot-policy evaluation in July 2026. That makes Instance an adaptive robotics-infrastructure company whose learning rate is stronger than its required-capital profile. The pivot matters. The product’s maximum stated ambition does not yet. Instance automates watching rollouts and recording outcomes; it does not yet name the economic mechanism that breaks when evaluation becomes free. Faster robot development could eventually move a civilizational variable, but a success detector is presently a tool inside the existing robotics regime, not a replacement for it.

**Slash** is the high rung on founder learning rate because a documented pivot revealed founders who updated their thesis faster than the market, and that mechanism helped override modest consequence magnitude. Instance shares that mechanism: Instance abandoned a recently promoted data-analyst product and produced a robot verifier within five months. Instance diverges because the dossier provides no explanation of what evidence falsified the original thesis, no customer pull behind the new thesis, and no current-product revenue. A pivot is evidence of learning, not evidence of destiny. I give meaningful credit because pre-seed founders rarely demonstrate even one genuine thesis update, but Instance remains below the Slash rung until the update produces customer behavior rather than another launch.

**DoorDash’s** required-capital weakness was a commodity-software and logistics profile with no scientific milestone that needed my capital; exceptional distribution and founder ambition ultimately overrode that mismatch. The same weakness appears more starkly in Instance. Instance offers an HTTP API, runs a fine-tuned local verifier in 2.0 seconds, and identifies no need for more than ordinary pre-seed software capital. No foundation-model training program, robot fleet, plant, or hardware deployment requires a $50M check. The DoorDash exception does not apply yet: Instance has 393 LinkedIn followers, 35 YC launch votes, and no documented customer deployment or distribution flywheel. I am over-resourced for Instance as currently designed.

Instance’s 10,000 labeled episodes across seven robot platforms place its consequence case above a generic workflow wrapper but far below **Physical Intelligence** on this axis. Physical Intelligence seeks general robot intelligence capable of displacing physical labor; Instance determines whether an attempted task succeeded. Instance could become essential measurement infrastructure for that transition, because systems improve only as fast as feedback becomes reliable. Yet the dossier names no labor-cost pool, incumbent evaluation regime at risk of disappearing, or autonomous loop connecting verdict, reset, retraining, and redeployment. The proposed reset robot is not launched. Instance currently accelerates the people building the revolution; Instance does not yet constitute the revolution.

Instance’s fine-tuned verifier compounds only if customer-approved verdicts create a proprietary distribution of robots, tasks, failures, and camera conditions over the next 18 months. The 0.76 macro F1 against Claude Opus 4.8 at 0.53 is a real technical signal, and 2.0-second latency versus 5.2 seconds shows Instance is not merely forwarding video to a commodity API. The mechanism fails if Robocurve’s MIT-licensed tooling, Bifrost’s open-source Manifold, or Runway’s world-model evaluation improves faster than Instance accumulates production data. Instance has a model advantage today, not a structural moat. Company-run benchmarks across eight held-out datasets establish technical competence; they do not establish the capital-hostile science risk that repels consensus venture firms.

MIT, CSAIL, NASA JPL, SpaceX, and Blackrock Neurotech give Instance unusually relevant founder credentials, satisfying my unstated preference for founders with intellectual reputation before financing. Credentials alone are not contrarianism. Instance presents no public claim from Mao or Cai contradicting robotics orthodoxy, and “manual video review should be automated” is a consensus observation. The score would flip a tier if Instance demonstrated that real-camera verification can replace simulation-centric evaluation across heterogeneous fleets—an assertion that would directly challenge One Robot, Bifrost, and Runway—and supported it with third-party production results. Until then, Instance’s founders look like capable adjacent experts pursuing a sensible opening, not instigators defying their field.

Instance’s February-to-July pivot and low-capital API profile produce a specific forecast: by July 2029, Instance will have pivoted from standalone policy-success detection into robotics data quality and observability, reaching $2M–$5M ARR while remaining a feature-scale software vendor rather than a capital-deep robotics platform. Instance will make that move because verdict generation naturally expands into dataset filtering, failure taxonomy, regression monitoring, and fleet debugging, while open-source success detection compresses the original wedge. Learning rate will preserve Instance; limited consequence and capital depth will bound Instance.

Instance’s 10,000 labeled episodes, seven-platform coverage, and 23-point F1 advantage support the strongest opposing case: Instance could become the universal evaluation layer for physical AI, with every robot rollout generating proprietary feedback and every new customer strengthening the verifier. The Slash exception says the pivot itself may be the signal, while Mao’s JPL work and Cai’s CSAIL robotics research fit my unstated academic-founder pattern. That case stings because evaluation is genuinely a bottleneck. It still loses today because Instance reports no production customer, no independent validation, and no autonomous reset loop, while three substitute paths are already named. I would flip to Invest if Instance reached $1M ARR from at least three publicly identified robot manufacturers using the verifier in production; that would show Instance is becoming infrastructure rather than a benchmarked feature.
