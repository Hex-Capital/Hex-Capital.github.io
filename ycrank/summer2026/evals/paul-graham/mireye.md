# Mireye -- Paul Graham Evaluation

Ansh Chokshi took Poker Pit to $250,000 ARR in four months and an acquisition, but Mireye contains no evidence that either founder personally suffered from missing geospatial data. That is Mireye’s signature: unusually strong evidence of animal resourcefulness attached to a suspiciously inorganic idea. Mireye has shipped 175 normalized fields, four REST endpoints, and an MCP server, so this is not a deck masquerading as a startup. But the best startups usually begin with “I needed this,” not “agents will need this.”

**Airbnb** is the high rung for resourcefulness because the cereal boxes produced revenue through an improbable stunt before investors believed the idea. Mireye shares the important mechanism: Chokshi has already shown he can force revenue into existence, reaching $250,000 ARR at Poker Pit in four months. Mireye diverges because that animal behavior belongs to the founder’s previous startup. Mireye’s free early access and unnamed design partners do not yet show Chokshi doing the unscalable thing for this product.

The polished AI-wrapper failure pattern begins with founders selecting an attractive market and planning to acquire conviction later. Mireye is better than that low rung: both founders are technical, and Mireye already exposes working endpoints with provenance, dataset vintage, retrieval time, and confidence. But Mireye’s dossier never says Chokshi or Shashwat Kapoor encountered this problem in their own work. Mireye may be a clever response to MCP adoption rather than an organic response to pain, and clever ideas are easier to abandon when users resist.

Mireye’s seven data layers create a genuine schlep because federal geospatial data does not become dependable merely by placing an API in front of it. Over 18 months, Mireye must reconcile incompatible schemas, stale agency releases, geographic gaps, and field-specific confidence while users blame Mireye for every bad answer. That work compounds if each failure improves normalization and coverage. It collapses into commodity plumbing if Mireye merely republishes USGS, NOAA, FEMA, USDA, EPA, EIA, and NREL data without learning from repeated queries.

Shashwat Kapoor has 32 public GitHub repositories and distributed-systems experience, while Chokshi led AI/ML engineering at Seismic and has nine repositories. Mireye therefore has builders, but not yet the unmistakable hacker genealogy of a Collison or Aaron Swartz. The score would flip upward if Mireye’s founders had built a widely used geospatial project before Mireye, or if the public API showed some technically surprising retrieval or normalization system rather than competent aggregation. GitHub stars are crude, but zero displayed stars for Chokshi and one on Kapoor’s pinned PlannrBot are not the tracks animals usually leave.

**Stripe** had two technical brothers whose shared history made the pair itself part of the evidence. Mireye also has the right numerical configuration: Chokshi covers AI and prior startup execution, while Kapoor covers data platforms and distributed systems. But Mireye provides no public evidence that the founders previously worked or built together. Two complementary résumés are not yet a strong pair; Mireye needs evidence that the founders remain effective when a federal dataset breaks at midnight and a design partner needs an answer by morning.

Mapbox’s 28 billion daily detections make a horizontal geospatial answer layer difficult to own, so my 36-month prediction is that Mireye will pivot from general-purpose agent infrastructure into property-insurance or real-estate underwriting data, reaching $1 million to $3 million ARR. Mireye’s resourceful founder can probably find a buyer for the normalization work, while Mireye’s weak organic origin makes a customer-led narrowing more likely than faithful execution of the present broad thesis.

Mireye’s strongest bear case is that it is an MCP wrapper over public data in a market where Mapbox and CARTO can add the same interface, with no proprietary dataset and no paid pricing. That case stings because Mireye lacks both the hacker-community pull of Dropbox’s demo and the founder-origin story of Stripe. I still lean invest because Chokshi’s $250,000 ARR result is unusually concrete, the working 175-field artifact precedes the pitch, and the reliability burden is precisely the kind of schlep mainstream founders underestimate. Mireye would lose my check if it cannot convert at least ten design partners into paying, repeatedly active customers within twelve months of launching pricing.
