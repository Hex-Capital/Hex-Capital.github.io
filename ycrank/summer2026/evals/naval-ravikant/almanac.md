# Almanac -- Naval Ravikant Evaluation

**Replit** is the high rung: a builder-tool distributed by code, where developers become the channel. Almanac has the same permissionless architecture—an Apache-2.0 CLI shipped through GitHub and PyPI, already earning 743 stars and 68 forks—but Almanac has no compounding user network. Almanac is therefore a high-leverage, low-network company: potentially the memory layer for coding agents, but currently a tool whose value resets with each repository. The divergence from Replit is consequential. Replit became an environment where users create; Almanac remains documentation that Codex, Claude Code, or Cognition could absorb.

**Perplexity** is the low rung on network effects: a single-sided product where one user does not directly improve the next user’s experience. Almanac exhibits the same weakness more starkly. Five displayed engineering teams may validate utility, but Almanac’s repository-local Markdown means cmux adding knowledge creates no automatic value for Conifer. Perplexity earned an exception through Aravind Srinivas’s rare retrieval expertise, pre-consensus AI timing, and extraordinary permissionless product distribution. Almanac has relevant retrieval talent, but Almanac has not yet demonstrated specific knowledge or category timing strong enough to receive the full Perplexity waiver.

Rohan Sharma’s ML research at the Vector Institute, CMU, and MIT can compound over the next 18 months if Almanac converts retrieval experiments into visibly better context selection across 843 commits, five design partners, and thousands of agent sessions. Almanac’s founders understand the ingredients—information retrieval, software engineering, and long-running Codex workflows—but specific knowledge is proven through artifacts, not credentials. With no public founder repositories found and no documented retrieval benchmark, Almanac sits above the generic ex-FAANG opportunity hunter but below the Stack Overflow founders building directly from years of public developer practice.

Cognition’s reported $492M run-rate revenue proves that coding agents are a large market, while Mintlify’s 20,000-company footprint proves that documentation can expand beyond a narrow feature. Almanac reaches a higher market score if repository memory becomes a vendor-neutral control plane spanning agents, incidents, code reviews, and organizational decisions. Almanac falls a tier if macOS plus Codex or Claude Code remains the product boundary. Support for Windows, Linux, multiple agent vendors, and a demonstrated pivot from “wiki” to “organizational memory protocol” would move the market assessment toward the top rung.

Almanac’s 843 commits are the strongest evidence of energy, and the plain-Markdown, Git-reviewable design shows intellectual honesty about generated documentation being fallible. Almanac parallels **Notion** only partially: both begin with an obsessive attempt to make knowledge programmable, but Notion had Ivan Zhao’s long personal history rebuilding tools, while Almanac presents three founders without a named CEO or documented record of operating together beyond Kushagra Chitkara and Rohan Sharma overlapping at Harvard. No integrity concern appears, but no ten-year-partner evidence appears either. Silence receives the neutral default; unresolved authority remains a real founder red flag.

Almanac’s 743 GitHub stars support a falsifiable forecast: within 36 months, Almanac reaches $3–8M ARR and is acquired by GitHub for integration into Copilot rather than becoming an independent network-scale company. Almanac’s permissionless open-source distribution can create broad developer adoption quickly, while Almanac’s absent cross-customer network and Apache-2.0 implementation make durable standalone capture harder. Code leverage creates the adoption; the missing network determines the exit geometry.

Cognition’s DeepWiki and Devin Search form the strongest bear case: Cognition, OpenAI, Anthropic, or GitHub already controls the agent interface, can reproduce repository memory, and can leave Almanac as an Apache-licensed feature with a “Let’s talk” labor-leverage sales motion. Almanac also triggers two quieter red flags—no named CEO and no public founder repositories—while Almanac’s five displayed users may be logos rather than durable usage. The evidence preventing a pass is the combination of 743 stars, 68 forks, local privacy-preserving operation, Git-reviewable Markdown, and actual distribution before a priced-round narrative. If Almanac cannot show at least 25 weekly active external teams or 10 non-founder contributors by January 2027, I withdraw the exception and pass. At today’s evidence level, I write a small wide-funnel check and preserve the option to double down.
