# Almanac -- Vinod Khosla Evaluation

743 GitHub stars and five displayed engineering-team users make **Almanac** a consequence-bearing wedge trapped inside a capital-light feature. **Almanac** scores highest on consequence because persistent institutional memory could let coding agents replace more engineering labor, but lowest on required capital because repository-local Markdown and a Python CLI need no $50M scientific wager. The economic mechanism that might break is repeated human explanation inside software development. Today, however, Almanac documents that mechanism rather than collapsing it.

**OpenAI** (2019) is the high rung on consequence: persistent machine intelligence could redirect nearly every knowledge industry. **Almanac** shares one load-bearing mechanism—agents become more economically substitutive when they retain architecture decisions and failure history across sessions. But **Almanac** diverges where consequence becomes product scope: five displayed users are adopting a self-updating wiki, not eliminating a named labor category, and Cognition already controls DeepWiki and Devin Search. OpenAI changed the possible world. Almanac may improve the context window.

**DoorDash** (2013) is the low rung on required-capital fit: capital-light execution offered little of my usual advantage, although consumer-commerce consequence eventually supplied the exception. **Almanac** has the same capital mismatch without DoorDash’s demonstrated market-scale override. An Apache-2.0 CLI, local indexing, repository-owned Markdown, and PyPI distribution can be built and tested with ordinary pre-seed capital. **Almanac** gives me no identified foundation-model training bill, fleet, plant, or scientific milestone where a concentrated Khosla check changes the outcome.

Cognition’s $492M run-rate revenue makes the technical-risk mechanism uncomfortable for **Almanac** over the next 18 months. Every accepted wiki edit could improve retrieval, but Apache-2.0 code and Git-reviewable Markdown let competitors copy the visible machinery while Cognition and coding-agent vendors possess the underlying conversations and repository interfaces. **Almanac** therefore compounds usage more readily than proprietary advantage. Knowledge accuracy is an engineering problem; it is not a falsifiable scientific miracle comparable to catalyst yield, solid-state chemistry, or fusion confinement.

Rohan Sharma’s research experience at the Vector Institute, CMU, and MIT establishes technical competence, not defiance of expert consensus. **Almanac** would flip this dimension upward if Kushagra Chitkara or Rohan Sharma demonstrated that repository-owned semantic memory produces materially better autonomous coding outcomes than native vendor memory—say, a published benchmark showing fewer regressions across 100 long-running tasks. Without that evidence, **Almanac** resembles experts extending current retrieval practice. Experts extrapolate the past; credentials do not prove an instigator.

**Slash** earned its learning-rate exception through a documented pivot whose reasoning became part of the company’s evidence. **Almanac** supplies no comparable pivot, prior exit, or public “we were wrong” moment for Kushagra Chitkara, Rohan Sharma, or Divit Sheth, so the absent-evidence default applies. Almanac’s 843 commits and version 0.1.5 demonstrate iteration, but commit volume is not thesis revision. Learning rate means changing the model of reality, not merely shipping the model faster.

Cognition will acqui-hire **Almanac** within 36 months for repository-memory talent after **Almanac** fails to exceed $1M ARR as a standalone wiki product. The mechanism is platform absorption: coding-agent vendors already own the interaction stream, while Almanac’s local privacy posture and agent-conversation ingestion make its founders and implementation useful inside a larger stack. **Almanac** can create adoption without retaining enough proprietary surface to create an independent economic regime.

Five named users, 743 stars, and 68 forks form the strongest bull case for **Almanac**: open-source distribution plus repository-local privacy could become the developer-trust wedge, just as capital-light **DoorDash** became a known exception to my science-risk preference. The objection stings because coding agents do need durable memory, and the neutral Markdown layer could span Codex and Claude Code rather than serving one vendor. The dossier still gives **Almanac** no proprietary dataset, measured retrieval advantage, revenue, or structural barrier, while Cognition and Swimm already occupy adjacent territory. I would flip to Invest if Almanac reaches $2M ARR from at least 30 paying engineering organizations while publishing evidence that cross-agent memory materially reduces regressions or human interventions.
