# Mireye -- Elad Gil Evaluation

175 normalized fields across seven data layers make Mireye an execution-ready infrastructure product with a clean single-miracle architecture, but Mireye’s free early access and unnamed design partners provide no commercial curve. That high-architecture/low-velocity pairing defines Mireye: the technical layer exists, while the evidence that anyone urgently needs it does not. This is closer to a capable data product searching for its market than something already “just working.”

**Color Genomics** is the high rung for the single-miracle test: workflow infrastructure built on commodity sequencing rather than a wager on new science. Mireye shares that mechanism by normalizing existing USGS, NOAA, FEMA, USDA, EPA, EIA, and NREL data instead of inventing new sensing technology. Mireye diverges because Color embedded itself in a consequential healthcare workflow, while four REST endpoints and an MCP server do not yet establish that Mireye’s normalization is indispensable rather than technically convenient. The architecture passes my unstated workflow-on-top-of-hard-thing pattern, but the workflow position remains unproven.

**Lyft** exposed the low-rung failure mechanism: a visible product can still be the wrong bet when its curve does not demonstrate a path to structurally superior economics. Mireye is earlier, but the warning is sharper because Mireye discloses no revenue, query growth, repeat-usage rate, or named design partner; “free during early access” is not a curve. For an AI-infrastructure company, that silence activates my explicit red flag: if adoption is explosive, it is usually easy to show. Mireye receives the absent-evidence default here because 175 fields measure supply created, not demand compounding.

MCP adoption is Mireye’s plausible market catalyst, but Mireye has not shown that MCP changed the economics of geospatial data rather than merely changing the interface. Over 18 months, a real catalyst would compound through agent integrations, query telemetry, improved schemas, and lower integration costs for every subsequent developer. Mireye could then skate for the puck as physical-world agents proliferate. If Mapbox or CARTO adds equivalent MCP access before Mireye accumulates proprietary usage feedback, however, the catalyst accrues to the incumbents and Mireye becomes a thin adapter over steady-state federal data.

Mapbox processes 28 billion daily map detections, which frames Mireye’s index-position counterfactual. Mireye moves into the invest tier on this dimension if every physical-world agent needs Mireye’s provenance-bearing answer layer regardless of which mapping, insurance, energy, or logistics application wins. Mireye stays below that threshold while developers can call federal datasets directly or obtain adjacent capabilities from Mapbox, CARTO, and Foursquare. A hosted MCP endpoint is distribution access; it is not yet “an index on physical-world AI.”

Ansh Chokshi built Poker Pit to $250,000 ARR in four months before acquisition, giving Mireye a real **Perplexity**-style founder parallel on shipping rather than pedigree. Mireye also pairs Chokshi’s AI/ML experience with Shashwat Kapoor’s data-platform and distributed-systems background, which fits the product being built. The missing Perplexity signal is iterative evidence from the current market: Mireye names no artifact shipped in response to a design partner, no usage loop, and no week-over-week expansion. Prior velocity earns substantial credit, but it cannot substitute indefinitely for Mireye’s present execution rhythm.

Four documented REST endpoints and a hosted MCP server lead me to predict that by July 2029 Mireye will have pivoted from a horizontal “physical-world AI” API into property-risk or insurance-underwriting data infrastructure and reached roughly $1 million to $3 million ARR. Mireye’s normalized hazard, parcel, environmental, and infrastructure fields are usable building blocks, but the missing horizontal demand curve will force Mireye toward a vertical where provenance and dataset vintage directly affect a buying decision. The single miracle survives; the generic distribution thesis does not.

Ansh Chokshi’s prior $250,000 ARR sprint is the strongest case that this forecast is too conservative: Mireye could combine a founder who has monetized quickly, 175 already-normalized fields, design-partner feedback, and MCP’s distribution shift into the default location context layer for agents. That would resemble the **Color Genomics** exception—workflow infrastructure on top of a commodity hard layer—and could become a small-scale Stripe pattern. The evidence that wins today is Mireye’s absence of named customers, paid usage, retention, or proprietary data while Mapbox, CARTO, and public agencies remain viable substitutes. I would flip to Invest if Mireye converts at least five design partners to paid contracts, exceeds $50,000 MRR, and sustains more than 20% monthly growth for three consecutive months without relying on bespoke services.
