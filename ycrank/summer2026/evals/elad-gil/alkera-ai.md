# Alkera AI -- Elad Gil Evaluation

Coding agents can now modify production data systems, data teams are the buyer, and the controlling variable is whether Alkera AI can make those teams comfortable granting agents write access without increasing escaped errors. The product is built around that variable: column-level lineage, downstream-impact mapping, graph-based planning, verified organizational knowledge, and approval gates for destructive SQL or shell actions. But the dossier never establishes the threshold at which technical reliability becomes purchasing behavior. An 83.28% Pass@1 benchmark is evidence that the agent works; it is not evidence that a data leader will authorize it to act.

The architecture is the strongest part of the company. Alkera retains workflow state through lineage graphs and team knowledge, controls permissions, and spans IDE, CLI, and browser surfaces. A stronger underlying model should improve task completion while leaving Alkera responsible for context, impact analysis, and production controls. That is more durable than an output wrapper. The qualification is that Looker, Tableau, Power BI, Metabase, Sigma, and Hex integrations remain “coming soon,” so the claimed whole-stack workflow is not yet whole-stack in documented deployments.

The economic discontinuity is much less clear. Agentic coding makes autonomous data work newly possible, but the dossier does not quantify fewer engineering hours, faster pipeline delivery, lower incident cost, or a margin improvement for customers. The $17.9 billion data-integration market is too broad to answer this. Meanwhile, PromptQL already combines shared context with deterministic permissions, Altimate offers SQL and dbt agents for $29 per seat, and Prophecy has raised $113.5 million. This market is crystallizing before Alkera has shown a distribution or cost advantage.

The strongest bull case is the combination of technical competence and an early product that already exceeds five displayed agents on DataAgentBench. Rick Gao, Tony Li, and Andrew Tran have relevant experience across quantitative systems, distributed computing, multi-agent software, data infrastructure, and machine-learning research. But the benchmark covers only 54 queries, and Alkera leads SCRIBE by 1.43 percentage points. That is not a scarce-technology exception: it neither demonstrates frontier research nor creates a structural barrier against well-capitalized data platforms reproducing the feature set.

Demand is therefore the unresolved gate. The dossier identifies no revenue, named customer, repeat deployment, retention, or production capacity constraint. Published $50 and $250 monthly plans are packaging, not product-market pull; 542 LinkedIn followers are attention, not usage. The founders have credible founder-market fit, but their biographies document neither prior startup learning nor a costly commitment that distinguishes this from a talented first-time team.

I pass today. Alkera AI has built the right kind of workflow architecture, but it has not yet shown that reliability changes customer authorization or economics before competitors absorb the same controls. One verifiable condition would flip me: five named customers each allowing at least 100 agent-initiated production changes per month for three consecutive months, with paid renewals and fewer than 1% requiring rollback.
