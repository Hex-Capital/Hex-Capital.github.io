## The Idea

- **Problem:** Chemical-process engineers manually assemble diagrams, equipment information, operating data, and specialized simulation tools into models, making design and optimization workflows slow and fragmented ([Dualizer’s LinkedIn announcement](https://www.linkedin.com/company/dualizer-yc-f26)).
- **Approach:** KinetIQ uses a deterministic simulation engine while its Vantage copilot proposes model changes for engineers to review and approve ([Dualizer, via search snippet](https://dualizer.com/)).
- **Differentiation:** [Inferred]: Dualizer emphasizes conversational model construction and reviewable changes, whereas Aspen Plus emphasizes process-model coverage and AVEVA emphasizes equation-oriented simulation and engineering-system integration; comparative performance: No public data found ([Dualizer, via search snippet](https://dualizer.com/), [AspenTech](https://www.aspentech.com/en/products/engineering/aspen-plus), [AVEVA](https://www.aveva.com/en/products/process-simulation/)).
- **Business Model:** [Inferred]: Enterprise software licensing is a possible monetization path given customer-specific deployment work; pricing: No public data found ([YC job description](https://www.ycombinator.com/companies/dualizer/jobs/DKxXnTw-forward-deployed-process-simulation-engineer)).
- **TAM/SAM:** The broader chemical-process-simulator market was estimated at $1.77 billion for 2025, reaching $2.93 billion by 2032 at 7.43% CAGR; Dualizer-specific SAM: No public data found ([360iResearch, November 2025](https://www.researchandmarkets.com/reports/6129961/chemical-process-simulator-market-global)).
- **GTM / Distribution:** Public outreach targets process engineers, and its advertised forward-deployed role customizes customer simulation environments with proprietary data, unit models, and kinetics ([LinkedIn](https://www.linkedin.com/company/dualizer-yc-f26), [YC](https://www.ycombinator.com/companies/dualizer/jobs/DKxXnTw-forward-deployed-process-simulation-engineer)).

## Defensibility

- **Moat today:** Dualizer describes a proprietary deterministic simulation and optimization engine, but patent protection or exclusive datasets: No public data found ([YC](https://www.ycombinator.com/companies/dualizer)).
- **Future moat:** [Inferred]: Customer-specific calibrated models could create switching costs if embedded in recurring engineering decisions, although retention evidence is unavailable.
- **Market structure:** [Inferred]: No structural barrier to incumbent replication is established, given AVEVA’s existing support for machine-learning models, digital twins, and engineering integration ([AVEVA](https://www.aveva.com/en/products/process-simulation/)).
- **Commoditization risk:** Researchers have demonstrated natural-language control of AVEVA Process Simulation through MCP, providing a documented route to overlapping functionality using an existing simulator ([Liang et al., January 2026](https://arxiv.org/abs/2601.11650)).

## Key Risks

- **Technical validation:** Dualizer’s indexed website says calibration demonstrations use synthetic histories and have not been validated on measured plant data, while engineer review provides an approval checkpoint ([Dualizer, via search snippet](https://dualizer.com/)).
- **Deployment customization:** [Inferred]: Requirements for proprietary data, novel equipment models, and custom kinetics could increase implementation work per customer ([YC job description](https://www.ycombinator.com/companies/dualizer/jobs/DKxXnTw-forward-deployed-process-simulation-engineer)).
