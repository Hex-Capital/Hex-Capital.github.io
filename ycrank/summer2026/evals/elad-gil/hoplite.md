# Hoplite -- Elad Gil Evaluation

Cloud coding agents can now continue after a laptop closes, engineering teams can buy completed work rather than additional chat seats, and Hoplite becomes large only if migrating local context produces recurring production changes that bundled platforms cannot deliver as cheaply or reliably. The dossier never turns that proposition into a measurable threshold. One installation converted ignored Sentry errors into proactive pull requests, but there is no deployment frequency, retention, setup-time reduction, revenue, or evidence that context migration—not the underlying agent—caused the result.

The market is real but already crystallizing. Cursor reports $4 billion in annualized revenue, Cognition $492 million, and Factory has raised more than $220 million. Those figures demonstrate adoption of cloud agents, yet they are adverse to Hoplite’s differentiation: Cursor already supports local-to-cloud handoff and reusable environments, while Factory offers persistent machines and alert-driven workflows. The inferred 2025–2026 infrastructure threshold therefore expands the category without showing that Hoplite captures better margins or distribution. A usage-credit model atop third-party compute could leave it bearing infrastructure and support costs while competitors bundle the same features.

The strongest evidence is architectural. Hoplite moves sessions, MCP servers, dependencies, and CLIs into persistent environments, then accepts work through Slack, Linear, iMessage, and Sentry. That is closer to owning an operational loop than formatting model output: stronger models should improve task completion while Hoplite retains environment state and trigger integrations. The first installation’s Sentry-to-PR behavior supports this mechanism. But there is no documented evaluation loop, proprietary state advantage, or structural integration barrier, and credential transfer introduces a serious security surface. The product is deeper than a prompt wrapper but not yet deeper than the platforms surrounding it.

Morrissey and Redmond have worked together across coursework, freelance projects, and prior startups; Morrissey dropped out, and their previous CarbonCopy product reached $855,000 in trading volume and more than 250 beta users. That is credible commitment and iteration experience, despite the volume not belonging to Hoplite. Their Stripe and AWS internships add relevant exposure, while the founders’ hands-on installations show willingness to learn the workflow directly. Current-product pull remains limited to one company-reported deployment with no disclosed payment or repeat-installation data.

The bull case is that manual “Collison” installations expose context and security failures that large IDE-centered vendors will treat as edge cases, allowing Hoplite to accumulate integrations and become the orchestration layer across competing agents. The founders’ prior product velocity and the first continuously operating installation make that more than a hypothetical. It still does not qualify for a frontier-team exception: the dossier shows capable young builders, not uniquely scarce model or infrastructure research, and no capital-intensive technical asset that incumbents must acquire. The red flag is simpler—Hoplite is entering a discontinuity by offering features the best-capitalized participants are already shipping.

I would pass today. My 36-month base case is that Hoplite pivots from general cloud-agent deployment to Sentry-triggered autonomous software maintenance and remains below $3 million ARR because the broader orchestration layer converges into Cursor, Factory, or Cognition. I would flip if five unrelated businesses each paid at least $5,000 per month for six consecutive months after self-serve installation; that would establish both repeatable pull and a defensible economic variable rather than one promising deployment.
