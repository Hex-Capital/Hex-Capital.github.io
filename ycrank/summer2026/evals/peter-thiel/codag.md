# Codag -- Peter Thiel Evaluation

Codag’s contested truth is precise: production agents will consume compressed, evidence-preserving log representations rather than raw logs or conventional search. The claim fails if agents solving real incidents cannot retain diagnostic accuracy while using materially fewer tokens. Codag has attempted that test: across synthetic LogHub2 incidents, it reports a 98–99% answer rate with 5.9–7.5 times fewer tokens than raw logs plus grep. This is a falsifiable technical proposition, not merely “AI infrastructure is growing.” But the experiment is internal and synthetic; it has not yet shown that heterogeneous production failures behave like the benchmark.

The secret may create value without letting Codag capture it. The initial market—log preprocessing for coding agents—is admirably narrow, but the dossier identifies no monopoly mechanism inside it. The deterministic engine adapts published Drain3 work, and both the engine and CLI are MIT-licensed. Sentry, Honeycomb, Dash0, and Cribl already possess telemetry, customer relationships, and adjacent diagnostic agents. Codag can be technically correct while becoming a feature supplied by companies that own the logs. Capitalism requires differentiation; here, the strongest evidence still points toward competition.

The bull case is sharper than the current adoption numbers suggest. Michael Zhou worked on infrastructure at Okta and Shopify, built a prior developer tool that reached 655 GitHub stars, and has already shipped a no-account CLI, API, MCP server, free tier, and explicit pricing from $19 to $499 per month. That combination shows technical fluency and an intuitive developer-distribution loop. Yet the current repositories have only 45 and 20 stars, no paying customer is disclosed, and five pivots make the earlier repository’s popularity evidence of founder reach rather than product demand.

The zero-to-one technical exception does not yet rescue the weak monopoly position. OpenAI’s competitive uncertainty could be overlooked after an unmistakable technical event; Codag’s material difference is that its result comes from 51 synthetic incidents evaluated by Codag itself. Reproducibility is intellectually honest, but independent production performance is what could convert an optimization into proprietary infrastructure. An incumbent reproducing deterministic grouping and placing it beside already-ingested telemetry remains the obvious counterfactual.

The founder is apparently building the core system himself, but full-time status, ownership, salary, and economic exposure are not documented. I treat that as missing evidence, not refutation. Nor is being solo automatically adverse. The more important structural concern is whether repeated pivots represent rapid search or an indefinite company assembled around whatever agent workflow is currently fashionable.

Pricing defines a plausible route but not yet a power-law engine. A $499 Team plan and custom Enterprise tier could support valuable infrastructure if usage expands with agent activity, while the self-serve CLI could feed enterprise sales. There is no disclosed conversion rate, sales cycle, retained production usage, gross margin, or revenue, however. My base case is that within 36 months Codag remains below $1 million ARR and pivots from standalone log compression into broader agent-observability or telemetry routing. The verifiable condition that flips me to invest is an independently evaluated corpus of at least 1,000 real production incidents on which Codag preserves diagnostic accuracy at more than fivefold compression while incumbent and open-source substitutes materially fail.

This is a real secret attached to an unowned market: technically interesting, economically unresolved. I would investigate rather than invest today.
