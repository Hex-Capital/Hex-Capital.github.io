# Glen -- Paul Graham Evaluation

Nikos Dritsakos sold SalesBop for $500,000 after 18 months, yet Glen has a team size of one. That pairing is Glen’s signature: a resourceful repeat shipper attempting a problem whose organizational breadth ordinarily demands a strong pair. I can imagine describing Nikos as an animal. I cannot yet imagine Glen surviving his bus factor.

**Airbnb** is the high rung for animal resourcefulness because the founders manufactured revenue with 1,000 cereal boxes when investors refused them money. Glen shares the more important mechanism: Nikos built and sold SalesBop, led AI product work at FliteHouse, handled SOC 2, and then worked on agent tooling at Composio before launching Glen into production. But Glen’s $500,000 prior exit is a credentialized result, not yet a Glen-specific stunt. There is no equivalent of selling a $4 box of cereal for $40, no named customer won through brute force, and no rejection overturned by a working artifact.

Glen’s team size of one occupies the solo-founder low rung because the failure mechanism is not insufficient intelligence; it is insufficient surface area. Glen must build retrieval, reconcile contradictory memories, reproduce source permissions, sell enterprises, and answer security reviews while Nikos remains the only founder. The nearest Known Exception is **Stripe**, where the Collisons’ prior Auctomatic outcome outweighed a process irregularity, but Stripe still had two Collisons. Nikos’s $500,000 SalesBop exit earns Glen extra attention. It does not repeal the cofounder red flag.

Glen’s organization-wide memory model creates a genuine schlep that will compound over the next 18 months. Every Slack integration, MCP client, OAuth 2.1 flow, and source-specific permission rule teaches Glen something competitors would rather wave away as implementation detail. But Glen currently shares everything learned across an organization unless private mode prevents writing, while Glean already has $300 million in ARR and enterprise distribution. If Glen embraces permission reconstruction and retrieval evaluation, the schlep becomes the asset, as compliance did for **Coinbase**. If Glen treats row-level security and encryption as the completed work, the schlep eats Glen instead.

Nikos’s work on agent tooling at Composio and AI product development at FliteHouse puts Glen near an organic idea, but the dossier never says Nikos personally lost a decision, watched an agent repeat a mistake, and built Glen for his own workflow. That missing sentence matters. To flip Glen into the top tier on founder-problem fit, I would need evidence that Glen began as Nikos’s internal memory layer at Composio or FliteHouse and was repeatedly used before anyone called it enterprise software. Without that evidence, Glen looks adjacent to his experience rather than forced out of it.

**Dropbox** reached me through Drew Houston’s working demo, not his MIT degree. Glen has more hacker evidence than a résumé-only founder: Nikos shipped SalesBop, held VP of Technology and Product responsibility, and has Glen running in production with MCP and Slack integrations. But Glen has no public GitHub repositories, open-source contribution, competitive-programming result, or Hacker News artifact. Nikos can plainly build; Glen has not yet shown the hacker genealogy that makes other hackers adopt something before the sales process begins.

Glean’s $300 million in ARR makes broad enterprise search a bad battlefield for one founder. By July 2029, Glen will have narrowed from “unified organizational context” to an engineering-agent context layer and reached $3 million to $8 million in ARR as an independent business. Glen gets there because Nikos’s resourcefulness can iterate toward a painful wedge, while Glen’s solo configuration makes a permission-complete organization-wide platform too broad to attack all at once.

Glen’s strongest bear case is commoditization: Glean, Dust, Unblocked, and the agent platforms can all add memory, while Glen has no disclosed revenue, no public retention data, no accuracy benchmarks, and no granular source-permission model. That case stings because the unstated hacker pattern is also weak—no GitHub trail—and the solo-founder red flag is explicit. I still invest because Nikos has already converted software into a $500,000 exit, worked inside agent infrastructure at Composio, and shipped Glen into production rather than merely publishing a deck. If Glen cannot show five paying organizations using its memory weekly for 90 consecutive days by July 2027, I flip to Pass.
