# Almanac -- Elad Gil Evaluation

743 GitHub stars, 68 forks, and five displayed engineering-team users make Almanac a high-single-miracle, low-index-position company: Almanac can build a useful product using capabilities that already work, but it does not yet control the layer where value compounds. The analytical signature is an easy-to-ship workflow product with authentic developer interest, no revenue curve, and a serious risk that coding-agent platforms absorb the feature.

**Color Genomics** is the high rung on single-miracle architecture: Color built workflow and data infrastructure atop commodity sequencing rather than betting on new chemistry. Almanac shares that mechanism because repository-local Markdown, conversation extraction, and local search require no new model breakthrough; Almanac mainly needs product execution and distribution. The divergence is that Color controlled a durable healthcare workflow, while Almanac depends on Codex and Claude Code interfaces that their vendors can change or internalize. The Color known exception partially applies, but Almanac has not yet shown Color’s control point.

**Lyft** exposed the low-rung failure mechanism for index positioning: occupying a secondary position in a market where the category leader captures the compounding economics. Almanac risks the analogous developer-tools outcome. Cognition already offers DeepWiki and Devin Search, while coding-agent vendors own the conversations and repository access; Almanac may improve as agent usage grows, but Codex, Claude Code, or Cognition can capture that growth directly. Repository-owned Markdown and local privacy give Almanac a wedge, not yet an index on coding agents.

Twelve-hour-plus and 16-hour Codex runs reported by Kushagra Chitkara identify a credible recent catalyst for Almanac: long-running agents are moving implementation history from human memory into ephemeral machine conversations. Over 18 months, more autonomous work should create more context residue, which increases the value of Almanac’s connected wiki and makes the market re-opening real rather than TAM theater. The weakness is that Almanac’s catalyst remains inferred from founder usage rather than demonstrated through broad customer behavior, putting Almanac below the post-Ukraine clarity that drove **Anduril**.

Five named engineering teams and 743 GitHub stars are informative pre-seed usage signals, but Almanac discloses neither revenue nor a time-series usage curve. The counterfactual is straightforward: six consecutive months above 20% paid-revenue growth, with at least 25 engineering teams repeatedly retrieving Almanac pages during agent runs, would move Almanac from developer enthusiasm to “just working.” Without that evidence, Almanac’s stars could be a false signal—interest in a legible open-source problem rather than buying behavior.

**Perplexity** is the relevant founder parallel because Aravind Srinivas repeatedly converted conversations into shipped artifacts. Almanac’s version 0.1.5 package, 843 repository commits, and functioning Codex and Claude Code integrations show a meaningful shipping rhythm; Almanac is more than three credentialed founders with a deck. The discount is attribution and operating structure: no prior independent products are identified for Kushagra Chitkara, Rohan Sharma, or Divit Sheth, and three founders are listed without a clear final decision-maker—an explicit scaling red flag in my framework.

Cognition’s $492 million run-rate revenue and existing DeepWiki distribution lead to a falsifiable forecast: by July 2029, Cognition acquires Almanac for less than $50 million after Almanac reaches between $500,000 and $2 million ARR. Almanac’s local, Git-reviewable memory layer is valuable enough to become a feature, but Almanac’s Apache-2.0 implementation and platform dependence make standalone compounding harder than product adoption.

743 GitHub stars, 68 forks, five named users, and repository-local privacy form the strongest opposing case: Almanac could become the neutral memory layer used across every coding agent, effectively a Stripe-like index on autonomous software development. That bull mechanism stings because cross-agent neutrality is precisely what platform vendors cannot credibly provide. Almanac still lacks a proprietary retrieval advantage, paid adoption, and evidence that users will preserve a separate memory layer once native platforms improve. I would flip to Invest if Almanac reaches $25,000 MRR while retaining at least 80% of team repositories over six months across two or more agent platforms.
