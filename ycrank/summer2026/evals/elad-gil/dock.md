# Dock -- Elad Gil Evaluation

Mike Molinet built Branch past $100 million ARR, while Dock has disclosed no revenue and its leading GitHub repository has one star. Dock is therefore a repeat-operator infrastructure wager whose shipping capability is far ahead of its demonstrated demand curve. Dock’s analytical signature is unusually strong founder execution paired with the exact AI red flag I worry about most: no evidence yet that the product is “just working.”

**Perplexity** is the high rung for founder shipping: Aravind Srinivas repeatedly built the artifact discussed a week earlier. Dock shares the important mechanism because Molinet and Govind Kavaturi already built together at Branch and Thena, including scaling international revenue from zero to $100 million ARR. Dock diverges because the dossier documents six repositories, a Mac app, an npm CLI, an MCP server, and a ChatGPT integration, but not iterative releases tied to user feedback. Dock sits just below the Perplexity rung: proven builders, with the between-meeting loop still unverified.

**Lyft** is the low-rung failure mechanism for signal quality: activity did not resolve whether the underlying economics supported the bet, particularly for a structurally disadvantaged entrant. Dock currently has an even thinner demand signal—commercial-beta status, one GitHub star, and no disclosed revenue, retention, or repeat usage despite published $19 and $49 plans. Pre-seed calibration prevents me from treating Dock’s silence as fatal, but Dock is an AI product, and a product already spread across six distribution surfaces should be able to show whether anybody keeps coming back. Until then, this is false signal rather than Harvey-style “just working.”

MCP adoption across Claude, ChatGPT, Cursor, and other clients is Dock’s credible recent catalyst, but the dossier labels the resulting market opening as inferred rather than documenting a measurable step-function in customer behavior. Dock is skating for the puck toward a real interoperability problem: agents from different vendors now need persistent shared state, permissions, and attribution. Dock’s market score would flip into the top quartile if customers were demonstrably moving from single-agent chats into multi-agent workflows because of MCP—not merely if more clients implemented the protocol. Named design partners adopting Dock within the last 90 days would establish that distinction.

Dock’s $19-per-organization pricing can compound only if the workspace becomes the durable system of record for agent actions rather than another interface beside CrewAI, Relevance AI, and Dust. Over 18 months, Dock’s identities, API keys, signed webhooks, audit history, and stored workspace state could create the unstated-pattern outcome I like: workflow infrastructure on top of the hard thing, with Dock benefiting automatically as agents proliferate. The failure mode is equally mechanical—model providers add shared state and permissions, leaving Dock to win feature-by-feature against vendors with more than $112 million of combined funding. Dock has an index-like architecture, but no evidence yet of index-like distribution.

**Color Genomics** is the relevant single-anchor parallel: workflow and data infrastructure sat on top of commodity sequencing, isolating the hard technical dependency rather than financing new science. Dock similarly assumes capable third-party agents and concentrates on permissions, shared state, and human-agent coordination; Dock does not need a new model breakthrough, new regulation, and new customer behavior simultaneously. The remaining miracle is that persistent multi-agent collaboration becomes a frequent workflow. The Color known exception therefore applies structurally, while the science-project red flag does not.

**Dust** has raised more than $60 million around enterprise multiplayer AI, but Dock’s broader MCP-native workspace and repeat founders make a focused outcome plausible. By July 2029, I expect Dock to reach $8 million to $15 million ARR from enterprise agent identity, permissions, and audit infrastructure, with the current $19 workspace product functioning mainly as the adoption wedge. Dock gets there if Molinet and Kavaturi use their Branch operating history to move upmarket before shared state becomes a bundled model-provider feature.

Six public GitHub repositories with one leading star make the bearish objection sting: Dock may be an accomplished pair of operators building a horizontal layer before buyers have a durable need, while Dust, CrewAI, Relevance AI, and the model vendors collapse Dock’s differentiation from both sides. Dock’s lack of proprietary data, network effects, WebAuthn readiness, and visible usage supports that bear case. I still invest because the founders have already scaled together, the MCP catalyst is specific, and Dock requires one market-adoption miracle rather than a chain of technical miracles. If Dock cannot disclose at least 25 paying organizations or three named enterprise deployments by January 2027, I would treat the curve as broken and flip the verdict to Pass.
