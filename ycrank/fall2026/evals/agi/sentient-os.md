# Sentient OS -- AGI Evaluation

**Action:** Pass  
**Evidence confidence:** Medium

### Company case

Sentient OS shipped a Mac app that runs a compact model overnight, updates an editable Markdown knowledge base, and uses that context to draft replies, queue suggestions for approval, and act across apps. The local design shifts some inference onto users’ existing Macs. The memo reports that Sidekick can hit limits on a user’s ChatGPT plan, but leaves open whether rising AI demand would make any input Sentient supplies persistently scarce. The building-blocks path scores zero. (The Idea, Key Risks)

The existing workflow has workers reconstructing context across email, messages, meeting notes, and files. Sentient’s design could reduce that labor, but the memo identifies no buyer or cadence that was previously uneconomic and became viable. It also leaves the cost per successful follow-up, including review and corrections, unmeasured. The enabled-industry path scores zero. Both zeros trigger Pass. (The Idea, Market & Traction)

The shipped alpha and the founders’ experience with desktop software and model compression support execution credit. Sentient reports more than 30 enterprises using the app, which supports modest demand credit while procurement, renewal, and payment remain unclear. Portable Markdown, public inference tooling, and documented overlap with native macOS features weaken durable value capture. Enterprise pricing and delivery costs are undisclosed, so scale economics stays at its default. (Founders & Team, Market & Traction, Defensibility, Key Risks, Key Facts)

### Countercase

If a Mac-based team could afford manual follow-up only intermittently and could approve local processing, overnight context assembly might make daily follow-up economical. The cross-app integrations and approval queue could still matter to that team if it had access to an equally capable model. This is a plausible seed-stage scenario. The reported enterprise usage does not establish that those teams were previously excluded, and the memo flags Full Disk Access requirements for some sources and cloud processing for some features. The countercase leaves the Pass gate in place. (The Idea, Market & Traction, Key Risks)

### Decisive diligence question

Can a paid enterprise pilot show that Sentient makes daily cross-app follow-up affordable for a team that could previously afford it only intermittently? A buyer-confirmed comparison of cost per successful follow-up should include review, corrections, and support, and test whether access to an equally capable model delivers the same workflow. A pilot that clears the buyer’s cost threshold and shows that Sentient’s integrations still matter would move the action to Reach out to test repeatability.
