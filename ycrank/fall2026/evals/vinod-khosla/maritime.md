# Maritime -- Vinod Khosla Evaluation

A dollar per agent per month could matter if Maritime makes persistent computing cheap enough to put useful expertise within everyone’s reach. But an agent slot is not a unit of completed work. The $20 plan buys 20 agents with concurrency limits; it does not establish the cost of delivering a reliable service. Maritime supplies no baseline for spending displaced, expert hours eliminated, or population newly served. I can imagine the consequential outcome. The dossier has not quantified it.

The technical question is whether snapshot-based sleep/wake changes the economics of persistent agents by an order of magnitude. Maritime has implemented persistent storage, encrypted secrets, and isolated computers. That is actual infrastructure work. But E2B already supplies sandboxes, Daytona offers snapshot/fork workflows, and Docker announced managed microVM sandboxes on September 24, 2026. There is no comparable-workload benchmark showing Maritime delivers 5–10x better cost, latency, density, or reliability. Monthly billing is a commercial choice; the underlying technical advantage remains unmeasured. This does not establish the red flag of merely wrapping a model, either. The evidence supports a functioning product with an unresolved discontinuity.

The strongest argument against passing is that these founders encountered the problem before selling the solution. Maria Gorskikh and Aryaman Shrivastava worked on MIT NANDA agent infrastructure and report hosting hundreds of research agents. Maria’s Open Instinct project, built using Maritime, has 416 GitHub stars. A founder who operates the workload can discover constraints that a generic cloud vendor misses. This fits my broader pattern of backing infrastructure platforms before their commercial importance is obvious. But the SDK’s seven stars do not yet establish a committed platform community, and project interest does not establish external production dependence. Their domain experience is relevant; the dossier provides no observed belief revision or difficult complementary recruiting against which to score the particular founder criterion.

Maritime’s cheapest decisive experiment should attack the conjunction of reliability and economics. Burst activity can produce retry responses, and memory snapshots expire after seven days. Those boundaries matter when customers expect an agent to resume its work predictably. Yet there is no disclosed experiment with a pass threshold, budget, and stop-or-change decision. Nor does approximately $1 per agent slot establish sustainable economics: utilization, storage, snapshot overhead, support, and paid add-ons determine the actual cost. I assign the missing-evidence defaults here. A three-person pre-seed team does not need a mature financial history, but its published subscription price cannot substitute for a cost model.

I pass at 25/100. My exceptions allow an unproven mechanism when a documented instigator and an enormous existing value pool make the option compelling; Maritime’s firsthand experience is promising, but that override is not established here. There is also no evidence of exit-seeking behavior or fundraising spent recklessly on scale. This is an unproven fit, rather than an actively disqualifying company. **My flip condition:** an independently reproducible production benchmark showing at least 10x lower fully loaded cost per successfully completed persistent-agent workload than E2B, at matched latency and reliability, with positive contribution margin. That would turn an attractive subscription proposition into evidence of a cost curve worth underwriting.
