# Conifer -- Paul Graham Evaluation

Charles Muehlberger built edge-AI devices for brain-injury modeling, while Conifer’s dossier gives no evidence that either founder personally suffered from runaway token bills. That pairing is Conifer’s signature: strong hackers carrying a possibly inorganic idea. Conifer has built something technically serious—a Rust inference engine reporting 194.6 tokens per second on an M3—but the dossier reads more clearly about what Conifer can build than why these founders had to build it.

**Stripe** is the high rung for hacker genealogy because the Collisons’ commerce experiments preceded the company and made the API feel like the natural next program to write. Conifer shares the artifact-first half of that mechanism: Conifer reports up to 60% faster decoding than llama.cpp, and Sage has earned 268 GitHub stars. Conifer diverges where it matters most. Neither Michael Jeffords nor Charles Muehlberger has a public personal repository, competitive-programming record, or hacker-community trail predating Conifer. The code is evidence of hackers; the missing genealogy prevents the stronger inference that hacking is how they habitually encounter problems.

**Kiko** exposed the danger of building a plausible software product without a sufficiently urgent organic need: clever code does not manufacture necessity. Conifer shows a similar weakness. Jeffords has ML and computer-vision experience, and Muehlberger researched edge inference, but Conifer provides no evidence that either founder operated a high-token coding-agent or support workload and built the router for himself. Conifer may have emerged organically from hardware research, but that is not the same as repeatedly feeling the customer’s pain. No evidence means applying the absent-evidence default here.

Michael Jeffords previously pushed hypertension screening through more than 20 barbershops to reach over 10,000 people. That is an animal-shaped track, though it belongs to HeartCheck rather than Conifer. At Conifer, shipping Juniper, assembling a 100-plus-developer waitlist, and publishing benchmarks can compound over 18 months because each hardware configuration creates another occasion to improve the engine and recruit users. But Conifer has not shown the equivalent of Airbnb’s cereal boxes: no revenue, no manual enterprise installation, and no customer Conifer won by refusing to accept no. I see resourcefulness, but not yet relentlessly resourceful behavior directed at the present problem.

OpenRouter’s approximately $50 million in annualized revenue makes Conifer’s schlep question unusually concrete. Conifer would move up a tier if local-first routing forced the founders into ugly deployments across Windows, Linux, GPUs, memory limits, security reviews, and customer-specific model evaluation—and Conifer embraced that work personally. The current evidence stops at selected Apple Silicon benchmarks and an unaudited local-only claim. Conifer is therefore closer to a clever software optimization than to Coinbase’s compliance grind. Hardware variability could become the schlep moat, but Conifer has not yet demonstrated willingness to live inside it.

**Dropbox** had a strong pair behind a demo that made the need immediately legible. Conifer also has two complementary founders: Muehlberger brings edge-inference and electrical-engineering research, while Jeffords brings ML development and physical-world operating experience. Conifer receives credit for the pair, but no public evidence describes how long the founders have worked together or whether they have survived disagreement. A pair is structurally better than a solo founder; an unexplained pair is not yet the Collison brothers.

Sage’s 268 GitHub stars point toward a specific 36-month outcome: by July 2029, Conifer will have pivoted from general least-cost model routing into enterprise local-inference deployment and governance, reaching roughly $1 million to $3 million in ARR rather than displacing OpenRouter as the default gateway. Conifer’s engine is the strongest artifact, while Conifer’s weakest evidence concerns an organic need for routing itself. Good hackers often discover the real company one layer below their first product.

OpenRouter’s 400-plus-model network supplies the strongest objection to that forecast: a local-first router promising 80% token savings could become the Dropbox-like utility developers install before anyone thinks of it as a market. Conifer already has 100-plus waitlist signups, 268 GitHub stars, and benchmarks ahead of llama.cpp, so the bull mechanism is genuine developer pull around a superior artifact. But Conifer has no reported revenue, no public routing-accuracy benchmark, and only 10 GitHub forks; stars do not yet prove repeated use. I would flip from Neutral to Invest if Conifer produced ten paying organizations using the router weekly, with independently measured savings above 50% and retention after three months.
