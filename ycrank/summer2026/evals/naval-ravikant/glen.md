# Glen -- Naval Ravikant Evaluation

Nikos Dritsakos’s $500,000 SalesBop exit makes Glen a specific-knowledge founder bet whose lowest dimension is the source of 10,000x geometry: Glen has no cross-customer network compounding as users join. Glen fits my unstated builder-tools pattern—agents are the new builders, and organizational memory is infrastructure for them. But code leverage in the product is not permissionless distribution. A work-email waitlist and founder-led calls are early enterprise labor, while no public GitHub repository or domain-writing audience shows organic pull. I would write a small angel check for the founder-product-market fit, not yet double down on the architecture.

**Replit** is the high rung for specific knowledge: Amjad Masad built code environments obsessively for years before capital caught up. Glen shares the load-bearing mechanism. Dritsakos worked on agent tooling at Composio, built AI sales-coaching software, managed AI products at FliteHouse, led SOC 2 work, and previously sold SalesBop after 18 months. Glen therefore comes from use, not a market-research memo. Glen diverges from Replit because no public repository, shipped technical artifact, or multi-year community predates the financing narrative. The knowledge is specific, but the public proof is professional history rather than an obsession visible in code.

**Perplexity** is the low rung on network compounding: every user receives value, but the next user does not automatically make the previous user’s product better. I waived that absence because Perplexity combined deep retrieval expertise, product-led distribution, and pre-consensus AI timing. Glen has a stronger local loop—each agent can write decisions and lessons that help later agents inside the same organization—but organization-level isolation prevents Glen’s hundredth customer from improving the first. That is accumulated customer data, not a network. The Perplexity exception only partly applies because Glen has founder-domain fit, but Glen has not demonstrated Perplexity-like organic distribution or a category lead.

MCP’s November 2024 release gives Glen code leverage: one protocol can reach clients backed by Anthropic, OpenAI, Google, Microsoft, and AWS. Over 18 months, Glen can replicate retrieval and memory software at near-zero marginal cost while every stored interaction improves an organization’s internal context. Distribution is the break in the compound-interest chain. Glen currently requires a work-email waitlist, founder calls, Slack installation, security review, and trust around sensitive data. Glen has code leverage in delivery but labor and permission in adoption. The explicit red flag of hiring SDRs before organic pull is absent—Glen lists zero jobs—but founder-led onboarding still pins the architecture below a native developer-distribution product.

The $4.87 billion enterprise-search market, projected to reach $8.85 billion by 2030, gives Glen a real market but not unlimited pivot-room. The counterfactual is clear: if Glen becomes the control plane for agent memory, permissions, provenance, and workflow across engineering, sales, and support, enterprise search becomes merely the first wedge into a platform-shaped market. If Glen remains a better RAG layer, Glean, Dust, Unblocked, and internal systems compress the opportunity. Glen moves up a tier only when customers use the same core record across multiple departments and agent clients without bespoke integration work. Today the dossier describes adjacent vectors, not demonstrated movement into them.

**Twitter’s** Ev Williams provides the clean single-anchor parallel for the 10-year-partner test: prior shipping and a completed exit supplied evidence of intelligence and energy before Twitter supplied metrics. Glen offers a smaller version of that signal. Dritsakos sold SalesBop for $500,000, reached VP of Technology and Product at FliteHouse, handled SOC 2, and then worked at Composio. Glen is solo-founded, so execution energy is concentrated rather than divided. Integrity has no positive or negative public evidence; I apply the neutral default. Glen also avoids the self-advertised-honesty red flag. One clean prior sale is evidence, but not yet a decade-long behavioral record.

Glean’s $300 million ARR shows that enterprises will pay heavily for organizational context, while Glen’s permission and retrieval risks suggest where the wedge will move. By July 2029, Glen will have pivoted from generic shared organizational memory into an MCP-native agent permissions and context-governance layer producing $5 million to $12 million in ARR. Glen’s specific knowledge makes that pivot plausible: Dritsakos combines agent tooling with SOC 2 experience. Glen’s missing network caps the outcome unless governance becomes a standard rather than an account-by-account feature. The likely business is valuable infrastructure SaaS, not yet a self-compounding protocol.

Glen’s production deployment with teams admitted in waves is the fact that prevents the strongest bear case from winning today. The bear mechanism is platform commoditization: Glean and Dust already possess enterprise distribution, memory and retrieval can become native agent-platform features, and Glen’s organization-wide sharing model can create a single permission incident that destroys trust. No retention data or accuracy benchmark disproves that case. Glen still has one advantage incumbents cannot purchase instantly: a founder who worked inside agent tooling before MCP became consensus, paired with a product already in production and no premature sales hiring. Optionality favors the small check. I would flip from Invest to Pass if Glen cannot show at least three paying organizations retaining for 90 days with weekly agent read-and-write usage by January 2027.
