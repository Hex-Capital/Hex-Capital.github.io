# Instance -- Naval Ravikant Evaluation

Lucy Cai’s CSAIL robot-learning research and Instance’s absence of any user-to-user network reveal the signature: Instance is a specific-knowledge company without compounding user-added value. The 10,000 labeled episodes across seven robot platforms show that Instance has built technical substance, not merely assembled a robotics pitch. But expertise compounds only inside the founders unless Instance turns customer verdicts into a shared data advantage. The smart and leveraged are getting richer; Instance is clearly smart, not yet fully leveraged.

**Stack Overflow** is the high rung for specific knowledge: developers built for developers after years of public work inside the problem. Lucy Cai’s robot-policy testing, SpaceX software, and CSAIL research place Instance well above a generic ex-FAANG opportunity hunt; Claire Mao’s JPL simulation work adds physical-systems intuition. Instance diverges from Stack Overflow because the founders pivoted from an AI data analyst only five months before launch, and neither has a deep public artifact trail comparable to Atwood or Spolsky. The 0.76 macro F1 against Claude Opus 4.8’s 0.53 proves Instance can ship specialized knowledge, but not yet that robotics evaluation is a decade-long obsession.

**Perplexity** is the low rung on network compounding: each user receives a useful answer without automatically making every previous user’s product more valuable. Instance has the same structural weakness. One robotics customer sending footage to Instance does not increase another customer’s supply, demand, or distribution; the proposed cross-platform training corpus is explicitly inferred, with no customer-approved data pool documented. Perplexity escaped this weakness through exceptional founder knowledge, permissionless product distribution, and pre-consensus AI timing. Instance has some of the first and third ingredients, but Instance’s office-demo sales motion lacks Perplexity’s consumer-scale product pull.

Instance’s HTTP API is code leverage at the production layer and labor leverage at the distribution layer. Over 18 months, serving another rollout can approach zero marginal replication cost, and a local verifier running in 2.0 seconds can be embedded deeply into automated testing. Yet Instance currently solicits robotics organizations and offers demonstrations at their offices; there is no open-source adoption, viral loop, public pricing, or organic developer channel. Code without permissionless distribution is software, not complete leverage. Unless Instance makes self-serve evaluation the default workflow, every customer still requires permission from a scarce enterprise buyer.

Seven robot platforms give Instance more pivot-room than the narrow phrase “success detector” suggests. The counterfactual that moves Instance into the Invest tier is straightforward: the same verifier must expand into automatic labeling, failure diagnosis, regression testing, and robotics observability without new hardware or a new buyer. Instance’s task captions and attempt segmentation support that path, while Foxglove’s $58.7 million in disclosed funding proves a broader robotics-data budget exists. Instance remains below that tier because no TAM, production deployment, or adjacent paid workflow is documented; open-source Bifrost and simulated evaluation from One Robot can also redirect the market away from recorded physical attempts.

Claire Mao and Lucy Cai have been friends for more than ten years, giving Instance a stronger partnership foundation than most two-person pre-seed companies. The single useful parallel is **Twitter**: Ev Williams brought a clean prior operating history, while Instance’s founders bring intelligence and energy but no completed venture that lets integrity be observed under pressure. Instance’s rapid pivot from AI data analysis may show adaptability rather than drift, and the 10,000-episode benchmark shows execution. I would still need time with both founders before calling Instance a ten-year game with ten-year people; friendship is evidence of durability, not evidence of governance.

Instance’s 0.76 macro F1 leads to a falsifiable forecast: by July 2029, Instance will have pivoted from a standalone success detector into broader robotics data-quality and observability software, reaching $1 million–$3 million ARR but remaining a single-sided enterprise tool rather than a network. Instance’s specific knowledge should carry the product into adjacent evaluation workflows, while founder-led deployment and open-source substitutes will constrain permissionless growth. That is a respectable software outcome. It is not yet the 10,000x geometry that pays for an angel portfolio.

Robocurve’s MIT-licensed tooling supplies the strongest opposing bull case: open alternatives could educate the market while Instance’s superior local verifier becomes the proprietary standard, and every approved customer verdict could improve Instance for every robot platform. That data-flywheel mechanism would turn today’s weakest dimension into the moat and make the current score look timid. The dossier does not yet support it: Instance names no production customer, no shared-data rights, and no third-party validation, while One Robot and Runway can eliminate physical-video evaluation through simulation. Three named robotics customers contributing reusable labels, combined with more than half of new usage arriving through self-serve API adoption, would flip my verdict to Invest.
