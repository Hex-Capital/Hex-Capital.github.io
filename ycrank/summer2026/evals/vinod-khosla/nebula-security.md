# Nebula Security -- Vinod Khosla Evaluation

The consequential version of Nebula Security is not better static analysis. It is turning scarce offensive-security expertise into continuous machine labor: every code change attacked, validated, and patched before release. But the dossier quantifies only a $10.65 billion application-security market and a $550 million SAST segment. It does not quantify breaches avoided, expert-hours displaced, or a 10–100x reduction in security cost. This is an important existing value pool, not yet a demonstrated societal discontinuity.

The technical evidence is real. Vega reports 1,393 validated findings, 1,356 Linux-kernel bugs, 98 public CVEs, and eight Chrome zero-days. The team has earned more than $400,000 in bug bounties, while its exploit repository has attracted 1,300 GitHub stars and 364 forks. These are doers, not AI tourists. Exploit reproduction also attacks the false-positive problem directly. Yet Nebula provides no controlled benchmark showing that Vega finds critical vulnerabilities five times faster, cheaper, or more accurately than OpenAI Codex Security, Microsoft MDASH, XBOW, or expert researchers. Accomplishment is not comparative discontinuity.

The founders have unusually strong founder-market fit: kernel fuzzing, program analysis, browser exploitation, smart contracts, Black Hat, DEF CON, Microsoft security, and academic systems research. That breadth explains why a four-person company can produce credible vulnerability work before meaningful commercial traction. It does not show fast belief revision or risk-tuned recruiting. The team remains concentrated in offensive-security research, with no documented instance of changing direction after customer evidence or recruiting an owner for enterprise deployment, repository trust, or economics.

The completed findings remove some capability risk, but capability is no longer the largest kill risk. The harder question is whether enterprises will provide sensitive repositories and pay repeatedly when frontier-model vendors and competitors funded with $40 million to more than $270 million offer overlapping systems. An enterprise private beta following a YC-company launch is useful, but no named customer, repeat deployment, pass/fail threshold, experiment cost, or stop condition establishes that capital is now attacking this commercial risk in order.

The strongest bull case is the exception case: four exceptional technicians enter a large, undeniable spending pool with a product capable of expanding from a narrow tool into security infrastructure. That resembles the mechanism behind the **Block** exception—small team, existing value pool, mutable platform—but the material difference is that Nebula has not shown either a platform expansion beyond vulnerability discovery or economics resistant to bundling by OpenAI and Microsoft. Its metered, per-repository, and fixed-audit models publish no prices, inference costs, human-research burden, or gross margins. The proprietary learning loop remains inferred rather than demonstrated.

I would pass today, narrowly. The downside is one check, but the uncapped side has not been established: this could become an excellent security company without becoming an asymmetric Khosla bet. One result flips me—a blind 90-day bake-off across three named enterprise repositories in which Vega produces at least five times more validated critical findings per dollar than Codex Security or MDASH, followed by paid repeat usage at 70% or better gross margin. That would convert impressive researchers into a measurable technical and economic discontinuity.
