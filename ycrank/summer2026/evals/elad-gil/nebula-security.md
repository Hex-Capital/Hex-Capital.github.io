# Nebula Security -- Elad Gil Evaluation

Nebula Security’s 1,162 validated findings, 98 public CVEs, and $400,000-plus in Google bounties define an exceptional vulnerability-discovery engine without an equivalent distribution engine. Nebula Security’s highest dimension is founder shipping: Eten Zou, Yuan Tan, Frank Wu, and Xiaochuan Yu have repeatedly produced exploits, patches, kernel findings, and public artifacts. Nebula Security’s lowest dimension is index-like positioning: VEGA must win share against OpenAI Codex Security, Gecko, ZeroPath, XBOW, and Semgrep rather than automatically compounding with application security. That high-shipping, low-distribution signature usually produces valuable technology; it does not automatically produce a durable standalone company.

**Perplexity** is the high rung for shipping because Aravind Srinivas repeatedly built the artifact discussed a week earlier. Nebula Security shares the load-bearing mechanism: Yuan built VEGA, Eten published kernel research, Frank led DARPA program-repair work, and Xiaochuan shipped a GitHub project with 412 stars. Nebula Security’s 1,162 validated findings are unusually legible evidence that the founders do more than promote. The divergence is iteration cadence: the dossier establishes a large body of shipped security work, but not repeat customer-feedback loops or material product changes between enterprise conversations. Nebula Security is closer to Perplexity than to a credential-only founding group, but the final step remains commercial iteration rather than technical output.

**Lyft** exposed the cost of entering a market where the structural winner may be someone else: strong execution does not repair a subordinate position in winner-take-all economics. That mechanism appears in Nebula Security through OpenAI Codex Security’s overlapping discovery, validation, and patch workflow, alongside Semgrep’s distribution, XBOW’s $120 million financing, and Gecko’s reported $440,000 ARR. Nebula Security has no current barrier forcing repositories through VEGA, and researcher validation makes Nebula Security look more like a differentiated service layered onto a replicable scanner than an index on secure software development. The exploit corpus could become infrastructure, but the dossier explicitly finds no evidence that customer-derived data already compounds.

Nebula Security’s $400,000-plus in Google bounties proves that its vulnerability work has economic value, but it does not prove that buyers are adopting VEGA. Over the next 18 months, the distinction between “just working” and a false signal will be whether the private beta turns per-repository subscriptions into expanding accounts; otherwise, every additional human-reviewed report increases validation labor without improving software gross margins. Nebula Security discloses no revenue, customer count, retention, or month-over-month curve, while competitor Gecko reportedly has $440,000 ARR. For an AI security product, silence on the curve remains a red flag even after applying pre-seed calibration.

OpenAI’s March 2026 launch of Codex Security is a specific catalyst, but it cuts both ways for Nebula Security: AI-generated code and AI-enabled offense expand review volume, while the same foundation-model vendors can absorb vulnerability discovery into existing developer workflows. Nebula Security would move into the top catalyst tier if enterprises were buying VEGA specifically because code volume or offensive activity had overwhelmed Semgrep and manual review—not merely because AI security became topical. The present evidence—enterprise private beta, pay-as-you-go pricing, and an inferred “why now”—places Nebula Security in a real reopening, but below the **Anduril** pattern where Ukraine visibly changed procurement behavior and contracts followed.

**Color Genomics** is the relevant single-anchor parallel: workflow infrastructure on top of a hard technical layer can capture value without underwriting new science. Nebula Security similarly builds analysis, proof generation, patching, and validation on top of existing models and program-analysis techniques; Nebula Security does not need new physics or a new regulatory regime. The complication is that VEGA presently needs two linked miracles: automated reasoning must remain materially better than model-provider scanning, and human validation must scale without becoming a services bottleneck. Yuan Tan’s statement that all reports receive human review and human-written patches prevents me from calling this a clean single-miracle architecture.

OpenAI’s Codex Security overlap makes my 36-month forecast a technology-acquisition outcome: Nebula Security is acquired by OpenAI for the Codex Security organization before Nebula Security exceeds $5 million ARR. The mechanism is the dimensional signature—elite exploit discovery and program-repair talent, demonstrated through 98 CVEs and eight Chrome zero-days, without a proprietary distribution position against platform vendors. Nebula Security can generate more strategic value inside the model-and-developer-tool layer than it can capture while selling repository subscriptions one account at a time.

Nebula Security’s 98 public CVEs and 1,186-star exploit repository make the strongest opposing case sting: the founders could follow the **Color Genomics** known exception, using researcher expertise to build workflow infrastructure above commodity models while validated findings create a proprietary feedback loop. Nebula Security could then become the trusted verification layer that every AI code generator must touch, closer to an index on AI-produced software than another SAST vendor. The dossier loses that argument today because no customer-derived data advantage, paying-customer count, retention signal, or scalable validation economics is visible. I would flip to Invest if Nebula Security reaches $1 million ARR with greater than 20% month-over-month growth and shows that most findings are validated without proportional researcher headcount.
