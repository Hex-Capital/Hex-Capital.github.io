## The Idea

- **Problem:** Enterprise IT teams lack centralized visibility and controls as internally built AI agents receive credentials and access production systems, leaving IT to tolerate the risk or block deployment ([YC company profile, Jul 2026](https://www.ycombinator.com/companies/decawork)).
- **Approach:** Decawork assigns each agent an identity, places credentials outside the agent, routes tool calls through a gateway, scopes permissions, gates sensitive actions with approvals, monitors runs, and records attributed audit logs ([Decawork security page, Jul 2026](https://decawork.ai/security)).
- **Differentiation:** [Inferred]: Unlike Astrix, Oasis Security, and Token Security, which primarily market non-human-identity discovery and security, Decawork combines identity governance with agent deployment, run monitoring, failure recovery, retirement, and auditing in one IT-operated control plane.
- **Business Model:** [Inferred]: The founder-led 30-minute demonstration and absence of published pricing indicate a direct-sales enterprise software model with negotiated contracts ([Decawork website, Jul 2026](https://decawork.ai/)).
- **TAM/SAM:** The broader identity-security market is forecast to grow from $29 billion in 2025 to $56 billion in 2029, implying an approximately 18% CAGR, but no public estimate isolates AI-agent control planes ([IDC forecast reported by TechRadar, Jan 2026](https://www.techradar.com/pro/crowdstrike-acquires-continuous-identity-firm-sgnl-for-usd740m-in-push-for-next-gen-security)).
- **GTM / Distribution:** [Inferred]: Decawork is pursuing founder-led enterprise sales to IT and security teams, supported by demonstrations and direct outreach to operators running production agents ([Decawork website, Jul 2026](https://decawork.ai/)).

## Key Risks

- **Product-pivot execution:** Decawork was publicly presented in June 2026 as an autonomous IT administrator for human-employee incidents, whereas its current website centers on an agent control plane, and the only disclosed production usage belongs to the prior product ([AI Engineer World’s Fair program, Jun 2026](https://www.ai.engineer/worldsfair/2026/llms-full.md); [Decawork website, Jul 2026](https://decawork.ai/)).
- **Incumbent convergence:** Okta announced native agent discovery, registration, lifecycle management, and a kill switch backed by its 8,200-integration catalog ([TechRadar, Mar 2026](https://www.techradar.com/pro/security/okta-unveils-new-framework-to-secure-and-protect-enterprise-ai-agents)).
- **Control-plane concentration:** Decawork’s gateway stores credentials and mediates agent tool calls, making its own compromise or outage a potential cross-agent access or availability event; no public security certification is listed on its trust page ([Decawork security page, Jul 2026](https://decawork.ai/security); [Decawork trust center, Jul 2026](https://decawork.ai/trust)).
- **Capitalized competitors:** Astrix, Oasis Security, and Token Security have raised $85M, $195M, and $27M respectively to pursue overlapping non-human and agent-identity controls ([Astrix, Dec 2024](https://www.prnewswire.com/news-releases/astrix-security-raises-45m-series-b-to-redefine-identity-security-for-the-ai-era-302327052.html); [Oasis, Apr 2026](https://www.oasis.security/newsroom); [Token, Jan 2025](https://www.prnewswire.com/news-releases/token-security-raises-20m-to-secure-enterprises-machine-identities--from-legacy-applications-to-ai-agents-302361620.html)).
