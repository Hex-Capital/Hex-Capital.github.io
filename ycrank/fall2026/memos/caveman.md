## The Idea

- **Problem:** Teams running coding agents such as Claude Code and Codex pay for context that agents repeatedly read, including tool output carried through multi-step sessions. ([Launch YC](https://www.ycombinator.com/companies/caveman), [Caveman About](https://caveman.so/about))
- **Approach:** Caveman Code runs Claude Agent, Codex, Cursor and its own context-selecting agent in one Mac or browser app, while Caveman Cloud turns workload traces into tests and rolls back trial changes when quality drops. ([Caveman Code](https://caveman.so/code), [Caveman Cloud](https://caveman.so/cloud))
- **Differentiation:** Edgee compresses context through a gateway for existing agents, Portkey provides gateway governance, and Factory supplies its own Droids, while Caveman combines a multi-agent desktop app, a proprietary coding harness and workload-level optimization. ([Edgee](https://www.edgee.ai/token-compression), [Portkey](https://portkey.ai/blog/series-a-funding/), [Factory](https://www.factory.ai/), [Caveman](https://caveman.so))
- **Business Model:** Caveman lists Code as free with existing keys or logins and offers monthly credit plans at $20, $60, $100 and $200, alongside a free individual Cloud tier and a $300/month Cloud Team plan with $300 of included usage. ([Caveman homepage, Nov 2026](https://caveman.so))
- **TAM/SAM:** Grand View Research estimates a $10.3B global AI code assistant market in 2026 with 22.5% CAGR through 2033, a broader category than agent cost optimization, for which no public SAM was found. ([Grand View Research, 2026](https://www.grandviewresearch.com/industry-analysis/ai-code-assistants-market-report))
- **GTM / Distribution:** Caveman distributes its free CLI through GitHub and npm, offers self-serve Code sign-up and Mac downloads, and invites teams to contact Brussee for direct onboarding. ([Caveman](https://caveman.so), [Launch YC](https://www.ycombinator.com/companies/caveman))

## Defensibility

- **Moat today:** The original open-source project gives Caveman a distribution channel with about 121K repository stars, and the company keeps the current Code harness proprietary. ([GitHub, Nov 2026](https://github.com/JuliusBrussee/caveman), [Caveman Code](https://caveman.so/code))
- **Future moat:** [Inferred]: Workload-specific evaluation sets and rollout histories could increase switching costs, with retention effects still unproven publicly. ([Caveman Cloud](https://caveman.so/cloud))
- **Market structure:** No structural barrier identified at this stage.
- **Commoditization risk:** Edgee already offers context compression for existing coding agents, and Palo Alto Networks acquired Portkey to integrate gateway controls into its security portfolio. ([Edgee](https://www.edgee.ai/token-compression), [Palo Alto Networks, May 2026](https://paloaltonetworks.gcs-web.com/news-releases/news-release-details/palo-alto-networks-completes-acquisition-portkey-secure-ai))

## Key Risks

- **Benchmark transfer:** [Inferred]: Savings may vary across customer workloads because Code’s published results come from company-run tests, while Cloud offers replay and limited-traffic rollouts with rollback. ([Caveman Code benchmarks](https://caveman.so/code#benchmarks), [Caveman Cloud](https://caveman.so/cloud))
- **Billing sensitivity:** JetBrains measured 8.5% fewer output tokens for the original skill, but the total test bill rose after one run crossed a long-context tier, illustrating why Caveman now tracks cost per successful task. ([JetBrains, Jul 2026](https://blog.jetbrains.com/ai/2026/07/speak-to-ai-agents-like-cavemen-tosave-tokens/), [Caveman About](https://caveman.so/about))
- **Hosted data handling:** [Inferred]: Cloud’s retention of redacted request and response bodies may complicate procurement for sensitive workloads, with paid storage controls and enterprise VPC deployment available. ([Caveman Privacy Policy](https://caveman.so/privacy), [Caveman Cloud](https://caveman.so/cloud))
- **Name collision:** Decrypt covered a separate `caveman-skill` repository by Shawnchee alongside Brussee’s project, so repository-level attribution matters when comparing adoption or benchmark figures. ([Decrypt, Apr 2026](https://decrypt.co/363440/devs-claude-talk-like-caveman-cut-costs-work-better))
