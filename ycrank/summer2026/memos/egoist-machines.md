## The Idea

- **Problem:** Users of multiple AI applications maintain separate, opaque memory profiles and must repeat preferences and history because those applications do not exchange context ([Y Combinator](https://www.ycombinator.com/companies/egoist-machines), Jul 2026).
- **Approach:** AI Passport stores user-approved context in one layer, lets applications request category-scoped and time-scoped access, permits revocation, and records reads and proposed writes in receipts ([developer page](https://ego.ist/developer), Jul 2026).
- **Differentiation:** Unlike ChatGPT and Gemini’s provider-specific memories, and Mem0 or Letta’s developer-managed agent memory, AI Passport presents itself as a user-controlled context layer shared across authorized applications ([OpenAI](https://openai.com/index/memory-and-new-controls-for-chatgpt/), Apr 2025; [Google](https://blog.google/products-and-platforms/products/gemini/temporary-chats-privacy-controls/), Aug 2025; [Mem0](https://www.prnewswire.com/news-releases/mem0-raises-24m-series-a-to-build-memory-layer-for-ai-agents-302597157.html), Oct 2025; [Letta](https://www.letta.com/blog/announcing-letta/), Sep 2024).
- **Business Model:** The consumer passport is advertised as free for life, while businesses and application developers can request pilot access but no developer pricing is published ([company website](https://ego.ist/), Jul 2026; [developer page](https://ego.ist/developer), Jul 2026).
- **TAM/SAM:** No public TAM/SAM data found for this specific segment.
- **GTM / Distribution:** The company is collecting a consumer waitlist, soliciting developer pilots, publishing an “Egoist Ideas” newsletter, and using Erin McGurk’s audience of more than 1 million followers across platforms ([GlobeNewswire](https://www.globenewswire.com/news-release/2026/07/13/3326210/0/en/Y-Combinator-Backed-Egoist-Machines-Launches-AI-Passport-the-Only-Way-to-Securely-Store-and-Share-Your-Personal-Data-Across-AI-Assistants-like-ChatGPT-and-Claude.html), Jul 2026; [Y Combinator](https://www.ycombinator.com/companies/egoist-machines), Jul 2026).

- **Market structure:** No structural barrier is identified because OpenAI and Google already bundle memory and personalization into their assistants, although their context remains provider-specific ([OpenAI](https://openai.com/index/memory-and-new-controls-for-chatgpt/), Apr 2025; [Google](https://blog.google/products-and-platforms/products/gemini/temporary-chats-privacy-controls/), Aug 2025).

## Key Risks

- **Incumbent substitution:** OpenAI and Google already offer controllable memory and personalization within ChatGPT and Gemini, allowing them to reduce the need for an independent layer inside their respective ecosystems; Egoist’s stated mitigation is portability across applications ([OpenAI](https://openai.com/index/memory-and-new-controls-for-chatgpt/), Apr 2025; [Google](https://blog.google/products-and-platforms/products/gemini/temporary-chats-privacy-controls/), Aug 2025; [Y Combinator](https://www.ycombinator.com/companies/egoist-machines), Jul 2026).
- **Integration coverage:** Passport utility depends on connected applications accepting its permission and memory interfaces; the developer page claims access to 800-plus connector sources but names no live developer customers or partnerships ([developer page](https://ego.ist/developer), Jul 2026).
- **Sensitive-data security and compliance:** Passport may process health, fitness, calendar, task, identity, and preference data, and the company states that absolute security cannot be guaranteed; mitigations include category-specific revocable passes, consent gating, read-only on-demand Google access, and no storage of Google user data ([privacy policy](https://ego.ist/privacy-policy), Jul 2026).
- **Permission friction:** Every application request can expose fields, purpose, and duration for approval, creating user-review overhead; the product supports defaults, editing, denial, revocation, and receipts as controls ([developer page](https://ego.ist/developer), Jul 2026; [GlobeNewswire](https://www.globenewswire.com/news-release/2026/07/13/3326210/0/en/Y-Combinator-Backed-Egoist-Machines-Launches-AI-Passport-the-Only-Way-to-Securely-Store-and-Share-Your-Personal-Data-Across-AI-Assistants-like-ChatGPT-and-Claude.html), Jul 2026).
