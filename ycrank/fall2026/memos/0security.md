## The Idea

- **Problem:** Developers and enterprise security teams must secure software as AI accelerates development and attacks, while their existing alternatives include periodic penetration tests and vulnerability scanners ([founder interview, September 2026](https://www.zsonline.ch/2026/09/16/hacken-auf-prophylaktisch)).
- **Approach:** The platform combines repository context, deterministic scanning and parallel AI agents to investigate attack paths, verify vulnerabilities and prepare remediation pull requests ([0.security](https://0.security/)).
- **Differentiation:** Against directly prompting Codex or Claude Code, the company claims scheduled testing, persistent codebase context, dedicated execution sandboxes and verified fixes ([0.security comparison](https://0.security/)).
- **Business Model:** Free accounts receive $50 monthly usage; a $30/month subscription adds $30 credits, additional usage costs $1/credit, and enterprise deployments have custom pricing without per-seat fees ([pricing, accessed October 2026](https://0.security/pricing/)).
- **TAM/SAM:** The broader application-security market was estimated at $10.65B in 2025, with 18.8% CAGR during 2026–2033; this is a category proxy, and company-specific SAM has no public data ([Grand View Research](https://www.grandviewresearch.com/industry-analysis/application-security-market)).
- **GTM / Distribution:** Distribution includes an open-source harness, self-service onboarding with free usage and founder-led enterprise consultations ([GitHub](https://github.com/0sec-labs/0), [pricing](https://0.security/pricing/)).

- **Moat today:** Published vulnerability-discovery evidence includes a JSONata advisory crediting founder Doruk’s GitHub account, demonstrating research execution without establishing exclusive IP ([JSONata advisory](https://github.com/jsonata-js/jsonata/security/advisories/GHSA-8gq3-vp5j-2grp)).
- **Future moat:** [Inferred]: Retaining customer architecture context and investigation history could improve subsequent testing, but a measurable advantage from accumulated context remains unverified ([product description](https://0.security/)).
- **Market structure:** [Inferred]: No structural barrier identified at this stage, given Aikido’s existing combination of code, cloud, runtime and autonomous penetration-testing products ([Aikido](https://www.aikido.dev/company/about)).
- **Commoditization risk:** [Inferred]: Security vendors can combine available models with agent orchestration, while 0.security’s public harness and Aikido’s overlapping offering reduce exclusivity at the workflow layer ([GitHub](https://github.com/0sec-labs/0), [Aikido](https://www.aikido.dev/company/about)).
