# Armorer Labs -- AGI Evaluation

**Action:** Watch  
**Evidence confidence:** Medium

### Company case

Armorer has an early building-blocks case in security verification for regulated enterprises deploying agents that access sensitive data. The potentially scarce input is security engineering capacity to verify what each agent can do, validate fixes against existing workflows, and clear releases. The memo cites Cobalt’s finding that roughly two-thirds of high-risk AI findings remain unresolved. That establishes remediation friction. The seed-stage assumption is that more agents and more frequent workflow changes will increase verification work faster than security teams can absorb it. The memo gives no buyer-level evidence of release delays or the time required to add equivalent verification capacity. (The Idea)

Armorer describes a workflow that checks proposed fixes against existing workflows before engineer approval and enforces policy at runtime. This could reduce the work required to clear a release. The Industry enabled by superintelligence score is zero because the memo identifies no previously excluded buyer, use, or verification cadence made economically viable by AI. (The Idea)

The Just Eat Takeaway testimonial supports a concrete customer use, and the SnapLogic discussions show exploratory interest. The founders’ prior AWS security work and Armorer’s published developer tools support execution at seed. SOC 2 Type 1 and customer-specific regression tests offer an early qualification and switching-cost case, with the switching costs still inferred. The company-run 50-document benchmark leaves production performance open, and the memo gives no paid deployment, pricing, or delivery-cost evidence to underwrite the next customer. (Market & Traction, Founders & Team, Defensibility, Key Risks, Key Facts)

### Countercase

The unresolved findings could reflect remediation priorities or approval requirements. In that case, faster verification may leave the release constraint in place. Buyers could also meet their requirements with bundled discovery, testing, and runtime controls or open-source policy enforcement. The memo documents those alternatives but gives no buyer comparison establishing equivalence for Armorer’s full workflow. That leaves a plausible path and a decisive, testable gap, supporting Watch. (The Idea, Defensibility, Key Risks)

### Decisive diligence question

Can Armorer clear a regulated customer’s agent release that is currently held up by security verification? A representative deployment showing that Armorer gets the release through the same approval requirements with materially less security engineering time than the customer’s best available alternative would move the action to Reach out. If the comparison shows that verification capacity was never the constraint or that the existing stack clears it just as readily, the action would move to Pass.
