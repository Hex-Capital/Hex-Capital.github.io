# Instance -- Elad Gil Evaluation

10,000+ labeled episodes and a 0.76 macro F1 make **Instance** a technically validated, single-miracle workflow product whose weakest signal is actual buying behavior. **Instance** has isolated a painful task—judging physical robot rollouts—and built something measurably better and faster than Claude Opus 4.8, but no revenue, named deployment, repeat usage, or signed LOI shows that the product is “just working” commercially. The dimensional signature is strong technical compression paired with an invisible usage curve.

**Color Genomics** is the high rung for single-miracle architecture: workflow and data infrastructure on top of commodity sequencing, without requiring new chemistry. **Instance** shares that load-bearing mechanism because the current product applies a fine-tuned verifier to existing camera footage rather than inventing robot hardware, foundation models, and autonomous reset systems simultaneously. **Instance** diverges where Color had control of the operating workflow: 0.76 F1 remains a company-run benchmark, compatibility across arbitrary robots and camera angles lacks external validation, and physical reset remains outside the launched product. The Color exception partially applies, but only to the narrow success detector—not the proposed autonomous evaluation rig.

**Lyft** is the low-rung failure mechanism for interpreting activity as economic proof: substantial usage does not rescue a structurally weak position, and false signals become especially dangerous when alternatives control distribution. **Instance** has even less commercial evidence—393 LinkedIn followers, 35 YC Launch votes, and no disclosed revenue—while Foxglove already occupies robotics observability and Robocurve, Bifrost, One Robot, and Runway provide substitute paths. **Instance** therefore receives the absent-evidence default on revenue velocity: 10,000 labeled episodes validate model development, not customer pull.

**Runway’s February 2026 policy-evaluation research** supplies a real but incomplete catalyst for **Instance**: robot foundation models are increasing rollout volume just as learned evaluators make automated review technically plausible. Over 18 months, that mechanism compounds only if more policies create more physical footage, more footage produces customer-approved verdicts, and those verdicts improve **Instance** across robot types. The first link is credible; the latter two remain inferred because no production deployment is named. This is a market re-opening, but it is closer to an early research transition than Ukraine revealing an immediate procurement gap for Anduril.

**Lucy Cai’s CSAIL robot-learning work and SpaceX software experience** put **Instance** above a credential-only founder profile, while Claire Mao’s JPL simulation work adds relevant physical-systems depth. The February-to-July 2026 pivot from an AI data analyst to a working robot verifier also shows that **Instance** can ship, but it does not establish the Perplexity pattern of building from weekly customer feedback. The score flips into the top founder-execution range if Mao and Cai can show three successive product changes requested by named robotics teams, with repeat API usage after each release.

**Stripe** became an index on e-commerce because every internet merchant eventually touched payments rails; **Instance** could become an index on embodied-AI experimentation if every policy rollout must pass through a neutral evaluation layer. Today **Instance** is a success-classification feature beside Foxglove’s data platform, Bifrost’s simulation orchestration, and open-source Robocurve—not yet the system of record. The index position becomes real only if the HTTP API accumulates cross-platform labels and embeds itself upstream of deployment decisions; otherwise Foxglove or a model vendor can absorb the feature.

**Instance’s 0.76 F1 and 2.0-second latency** lead me to predict that by July 2029, **Instance** will be acquired by Foxglove for under $50 million after reaching less than $3 million ARR, with the verifier folded into a broader robotics observability product. The mechanism is straightforward: the narrow single miracle works, but weak standalone distribution and open-source substitutes prevent the verifier from owning the workflow. Foxglove has the installed data path that **Instance** currently lacks.

**Instance’s 10,000 labeled episodes across seven robot platforms** support the strongest opposing case: the benchmark may be the seed of a proprietary evaluation corpus, and the 0.23 F1 advantage over Claude Opus 4.8 could let **Instance** become the default verification rail as embodied AI compounds. That would resemble the Color exception—workflow infrastructure on top of a hard technical category—more than a commoditized feature. The objection stings because the current technical artifact is unusually concrete for pre-seed, but the dossier still shows no customer-approved verdict corpus, named deployment, or repeat API usage; the data flywheel is hypothetical. I would flip to Invest if **Instance** reaches $1 million ARR with greater than 20% month-over-month growth and at least three named robotics customers using the API in production.
