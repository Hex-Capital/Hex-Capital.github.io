## The Idea

- **Problem:** Software teams using Codex, Cursor or Devin for repository work can hit subscription limits or face high inference bills as agents make repeated model calls during a task ([Launch YC, Nov 2026](https://www.ycombinator.com/launches/XUY-reason-the-most-efficient-agent-harness)).
- **Approach:** Reason runs its harness outside the execution sandbox, batches tool calls, and preserves session state across cloud and local machines so an issue, schedule or Slack alert can trigger work through to a pull request ([YC directory](https://www.ycombinator.com/companies/reason-machines), [Reason 1.1, Oct 2026](https://reasonmachines.com/blog/introducing-reason-agent-1-1)).
- **Differentiation:** Reason reported 22% lower cost per solved task than Codex using the same model, rolls over across connected subscriptions alongside Cursor’s overlapping cloud VM workflow, and batches tool calls where Devin Fusion pairs a lead model with a cheaper model ([Reason 1.1, Oct 2026](https://reasonmachines.com/blog/introducing-reason-agent-1-1), [Launch YC, Nov 2026](https://www.ycombinator.com/launches/XUY-reason-the-most-efficient-agent-harness), [Cursor Docs](https://cursor.com/docs/cloud-agent/capabilities), [Cognition Fusion](https://cognition.com/blog/devin-fusion)).
- **Business Model:** Pro costs $50 and Max $200 per person per month with separate weekly AI and cloud credit allowances, paid top-ups start at $20, and Enterprise is sales-priced ([Reason pricing docs, Nov 2026](https://docs.reasonmachines.com/docs/plans)).
- **TAM/SAM:** Menlo Ventures estimated $34B in enterprise AI coding spend in 2026, up 7.7× year over year, while Gartner estimated $9.8B–$11B annualized for enterprise AI coding agents as of April 2026 ([Menlo Ventures, Nov 2026](https://menlovc.com/perspective/2026-the-state-of-enterprise-ai/), [Gartner, 2026](https://www.gartner.com/en/articles/enterprise-ai-coding-agent-market)).
- **GTM / Distribution:** Reason offers self-serve onboarding through its web app and Slack, a Pro trial, and $1,000 in credits for YC companies ([Launch YC, Nov 2026](https://www.ycombinator.com/launches/XUY-reason-the-most-efficient-agent-harness), [Reason pricing docs](https://docs.reasonmachines.com/docs/plans)).

## Defensibility

- **Moat today:** Reason has published a harness that batches tool calls and keeps prompts and tools stable for caching, with a company-measured cost advantage against Codex on the same model and benchmark tasks ([Reason 1.1, Oct 2026](https://reasonmachines.com/blog/introducing-reason-agent-1-1)).
- **Future moat:** [Inferred]: Shared skills and connected workflows could raise switching costs if teams reuse them across projects, with no public retention or workflow reuse data found ([YC directory](https://www.ycombinator.com/companies/reason-machines)).
- **Market structure:** No structural barrier identified at this stage.
- **Commoditization risk:** Reason 1.1 builds on the public Pi harness, while Cursor already operates isolated cloud VMs and Cognition markets its own cost-optimized harness ([Reason 1.1](https://reasonmachines.com/blog/introducing-reason-agent-1-1), [Cursor Docs](https://cursor.com/docs/cloud-agent/capabilities), [Cognition Fusion](https://cognition.com/blog/devin-fusion)).

## Key Risks

- **Benchmark transfer:** [Inferred]: Customer cost per merged pull request may differ from Reason’s reported benchmark savings because its comparison prices model attempts on fixed tasks, with published methods and run logs available for reproduction ([Reason 1.1, Oct 2026](https://reasonmachines.com/blog/introducing-reason-agent-1-1)).
- **Provider dependency:** [Inferred]: Subscription policy or quota changes can interrupt connected accounts, with rollover and API-key support providing fallback ([Reason subscription guide](https://reasonmachines.com/guides/use-all-your-ai-subscriptions), [Launch YC](https://www.ycombinator.com/launches/XUY-reason-the-most-efficient-agent-harness)).
- **Cloud data handling:** Cloud runs process customer code and prompts through compute and model providers, with isolated compute, encrypted credentials and logged restrictions on staff review ([Reason privacy policy, Nov 2026](https://reasonmachines.com/privacy-policy)).
- **Brand discovery:** [Inferred]: Searches for “Reason” can surface Reason Studios’ music software because both products use the name, making the company domain useful for disambiguation ([Reason Machines](https://reasonmachines.com/), [Reason Studios](https://www.reasonstudios.com/about)).
