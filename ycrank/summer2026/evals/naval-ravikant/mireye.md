# Mireye -- Naval Ravikant Evaluation

Mireye’s 175 fields span a $102.7 billion geospatial market, but every API query remains economically independent of the next. Mireye is wide-market, thin-network infrastructure: abundant pivot room paired with almost no user-added compounding. Code is leverage, but an API is not automatically a network. Mireye can replicate answers at zero marginal cost; it has not shown that replication improves the product or distributes it.

**Uber** is the high rung for pivot room: black cars became UberX, then mobility, because the market surface was broader than the first product. Mireye shares that option geometry across hazards, terrain, utilities, parcels, energy, and environmental data. Mireye diverges because its current US-only coverage depends primarily on federal datasets, while Uber controlled an expanding marketplace of proprietary supply and demand. The $234 billion forecast for geospatial analytics leaves Mireye room to maneuver, but market size is optionality only when the founders can move faster than Mapbox and CARTO.

**Perplexity** exposes the low-rung network weakness: each user receives an answer without directly increasing the next user’s value. Mireye has the same single-sided architecture—one coordinate enters, structured fields leave—and Mireye’s design-partner feedback is not yet a compounding user network. I waived this weakness for Perplexity because Aravind Srinivas brought rare retrieval knowledge and entered AI before consensus. Mireye has neither public geospatial-specific founder artifacts nor evidence that its queries generate proprietary data, so the exception does not yet apply.

Mireye’s four HTTP endpoints and hosted MCP server can compound code leverage over the next 18 months: one integration can serve millions of agent calls without proportional labor. Mireye nevertheless confuses access with distribution if it assumes a public catalog creates pull. Ansh Chokshi’s GitHub repositories show no stars, Shashwat Kapoor’s pinned repository has one, and the only adoption evidence is unnamed design partners. Permissionless leverage begins when users arrive without permission; Mireye has built the machine but not the flywheel.

Ansh Chokshi led AI/ML engineering at Seismic and built Poker Pit to $250,000 ARR in four months, while Shashwat Kapoor brings scalable data-platform and distributed-systems experience. That is real specific knowledge in software infrastructure, but Mireye’s hard problem is normalizing unreliable geospatial sources, not merely serving APIs. The score flips into the top tier if Mireye can show that either founder spent years operating GIS systems or has already built a normalization artifact that Mapbox, CARTO, or direct federal-data users cannot cheaply reproduce. Today Mireye has adjacent expertise, not yet obsession-level founder-product-market fit.

**Twitter** benefited from Ev Williams having shipped and exited Blogger cleanly before the Odeo pivot. Mireye has a smaller but relevant parallel in Chokshi’s Poker Pit acquisition: shipping to $250,000 ARR in four months signals intelligence and energy, not résumé theater. Mireye provides no public evidence about the co-founder relationship, prior treatment of colleagues, or long-term integrity, so I apply the neutral integrity prior. Play long-term games with long-term people; a quick exit proves execution, not yet the ten-year relationship.

Mapbox’s 28 billion daily map detections make horizontal aggregation a dangerous place to remain undifferentiated. By July 2029, Mireye will have pivoted from general physical-world agent infrastructure into a US property and climate-risk underwriting API producing $1 million–$3 million ARR. Mireye’s broad field catalog supplies the pivot surface, while its absent network effects push Mireye toward a narrower workflow where provenance and dataset vintage can command payment.

**Perplexity** is the strongest bull objection: a single-sided API can become enormous when category timing, permissionless distribution, and specific knowledge converge. MCP adoption could make Mireye the default physical-world context layer before Mapbox or CARTO recognizes the interface shift; 175 normalized fields and confidence metadata are already more product than most pre-seed companies ship. The objection loses today because all source data is reproducible, no structural barrier is identified, and no organic adoption is public. I would flip to Invest if Mireye reaches 100,000 monthly agent calls across 50 unaffiliated paying customers and can demonstrate that query feedback creates proprietary coverage or reliability improvements.
