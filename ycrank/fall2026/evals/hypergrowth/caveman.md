# Caveman -- Hypergrowth Evaluation

**Action:** Watch  
**Evidence confidence:** Medium

### Company case

Conditional on strong product-market fit, Caveman’s strongest growth path is through Code. Developers and teams already running coding agents have a recurring need to control context costs. Code supports Claude Agent, Codex, and Cursor in a Mac or browser app, and developers can start with existing keys or logins. That makes the core workflow credible across markets wherever buyers can access those providers. Caveman’s GitHub and npm distribution gives it a plausible bottom-up channel, and Code documents self-serve signup and a Mac download. The path from signup to independent paid activation remains unverified. Cloud team onboarding is offered directly by the founder, with its role in routine deployments still unclear. (*The Idea*, *Key Risks*)

Code’s $20–$200 monthly credit tiers give retained customers a way to spend more as their workloads grow. Cloud’s $300 monthly team plan and workload-specific evaluation history could support recurring use. Expansion offsetting churn is plausible, with renewals and upgrades still unverified. Code launched in November and Cloud in October with a one-person team. The original repository’s roughly 121,000 stars show distribution reach, while the commercial status of the current products remains unknown. Initial traction therefore takes the absent-evidence default. (*The Idea*, *Defensibility*, *Market & Traction*, *Founders & Team*, *Key Facts*)

For a paid Code account, incremental contribution is credit revenue less any model usage Caveman funds, plus the effect of incremental infrastructure and support costs. When customers supply their own keys, they bear the associated model charges. If context selection also lowers usage on workloads Caveman funds, it could improve contribution. Caveman’s reported 21% reduction in list-price cost per solved task against Codex supports that possibility. Caveman’s actual model costs and Cloud’s replay, storage, and onboarding costs remain uncertain. The documented product and pricing support medium confidence in the growth mechanism, with paid conversion and contribution still open. (*The Idea*, *Market & Traction*, *Key Risks*)

### Countercase

Developers drawn to the free project may keep using their existing agent tools or stay on Code’s free bring-your-own-key tier. Caveman’s savings come from company-run tests, and a test of the original skill recorded a higher bill after one run crossed a long-context pricing tier. If paid demand concentrates in Cloud teams with sensitive workloads, hosted data handling and founder-led onboarding could slow deployment. The structural downside gate stays open because Code has a credible portable path and the memo does not establish that hands-on work or weak contribution is unavoidable. (*The Idea*, *Market & Traction*, *Key Risks*)
