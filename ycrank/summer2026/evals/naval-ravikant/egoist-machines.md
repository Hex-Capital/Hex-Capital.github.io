# Egoist Machines -- Naval Ravikant Evaluation

The founders have built useful capabilities around the problem, but they have not yet shown that they learned this particular problem through use. David Khachaturov worked on OpenAI’s PaperBench, led AI-security work at FrontierOne, and shipped a 4.7K-star GitHub project. Erin McGurk built educational channels reaching more than 1 million followers. These are real artifacts—technical leverage on one side, proprietary distribution on the other—but neither proves repeated contact with people trying to move memory between AI applications. Specific knowledge is adjacent, not yet exact.

The product identifies a real principal-agent problem. ChatGPT, Claude, and application developers control the memory; the user supplies the intimate data but does not control its movement. Field-level requests, expiration, approval, revocation, and access receipts are a coherent answer. Yet the proposed permissionless identity layer is presently permissioned by the applications: Egoist Machines needs developers to integrate and dominant platforms to permit access. No integration partners, active users, or repeat usage have been disclosed. A passport without countries accepting it is a well-designed document, not a network.

The harsher test is what remains after Mem0, Supermemory, Letta, OpenAI, or Anthropic copies the interface. The dossier identifies no proprietary model, exclusive data, hardware, protocol adoption, or established user graph. Accumulated context and standardized permissions could eventually compound, but “could” is not an asset. Native platforms already hold the data and control the APIs, while Egoist concentrates health, identity, OAuth, and preference information into a new security target. Copyable code plus ecosystem dependency is the structural failure mode here.

The bull case is stronger than the current score. McGurk can educate and acquire consumers through an audience reported at 515K on Instagram, 205K on TikTok, 55K on YouTube, and 5K on Substack; Khachaturov can credibly build the security layer. User ownership is also aligned with a permissionless system rather than another developer-controlled memory silo. If that distribution produces a large installed base, applications may integrate because users arrive carrying valuable context. The company could then turn consumer trust into a standard.

But there is no evidence of that loop yet. The waitlist opened July 13, 2026, the company has 268 LinkedIn followers, and no active-user, partner, referral, or integration metrics are public. The Passport is advertised as free for life, while developer pricing remains unstated. This is not a pre-seed traction penalty; it is an absence of evidence for the two mechanisms on which the company depends—network formation and direct value capture. No known exception overrides that absence because the dossier shows neither obsessive product usage nor a demonstrated self-reinforcing network. I see no founder-integrity or financing red flag; the objection is structural, not personal.

I pass today. Within 36 months, the most likely outcome is a pivot from consumer AI Passport to a B2B consent-and-audit product for AI applications, because developers can directly pay for compliance infrastructure while consumers are unlikely to coordinate platform adoption. One condition flips the decision: Egoist Machines demonstrates at least 25 independent application integrations and repeat cross-application use by 50,000 monthly active Passport holders, with developers paying recurring fees. That would convert an elegant permissions interface into a user-carried network that competitors cannot reproduce merely by copying the code.
