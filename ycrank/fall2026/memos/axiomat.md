## The Idea

- **Problem:** Teams that need reliable operational or financial answers fall back on dashboards, manual checks, or restricted AI assistants because a confident error can affect pricing and board reporting ([Axiomat About](https://www.axiomat.com/about), [Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate)).
- **Approach:** Axiomat converts business rules and natural-language questions into formal definitions, shows users its interpretation in plain English, and uses Lean to check that a generated query matches the definition before execution ([Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate)).
- **Differentiation:** Axiomat gates execution on a Lean proof, TextQL runs approved calculations and reconciliation scripts, WisdomAI adapts its context from user corrections, and Omni grounds queries in a governed semantic model ([Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate), [TextQL](https://textql.com/blog/ontology-ga), [WisdomAI](https://www.wisdom.ai/product/analytics-harness), [Omni](https://omni.co/blog/omni-series-c-funding)).
- **Business Model:** [Inferred]: Demo-led enterprise contracts are a plausible monetization path given product consultations and customer-specific rule setup ([Axiomat](https://www.axiomat.com/)).
- **TAM/SAM:** No public TAM/SAM data found for this specific segment.
- **GTM / Distribution:** Axiomat offers booked demos, invites launch readers to email the founders about stalled or restricted AI projects, and describes outreach by email and LinkedIn ([Axiomat Contact](https://www.axiomat.com/contact), [Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate), [Axiomat Privacy](https://www.axiomat.com/privacy)).

## Defensibility

- **Moat today:** The technical signal is a proof gate that blocks unproved queries and retries or abstains when it cannot establish a match ([Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate)).
- **Future moat:** [Inferred]: A library of customer-approved rules could create switching costs as more workflows depend on it, with public evidence currently limited to the rule-approval workflow ([Axiomat](https://www.axiomat.com/), via search snippet).
- **Market structure:** No structural barrier identified at this stage.
- **Commoditization risk:** [Inferred]: Snowflake already has semantic views and preapproved SQL examples, giving it an existing route to address the same buyer need, with the effort required to add per-query proofs unknown ([Snowflake Cortex Analyst documentation](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst), [Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate)).

## Key Risks

- **Specification fidelity:** [Inferred]: A valid proof can certify a query against an incorrect business rule or interpretation, which Axiomat addresses by having teams approve rules and showing users the interpretation covered by the proof ([Axiomat](https://www.axiomat.com/), via search snippet, [Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate)).
- **Proof coverage and latency:** [Inferred]: Retrying failed proofs may delay responses, and blocking unproved queries can leave valid questions unanswered, with abstention as the documented fallback ([Launch YC](https://www.ycombinator.com/launches/X3M-axiomat-agents-that-cannot-hallucinate)).
- **Platform substitution:** [Inferred]: Buyers satisfied by semantic views and approved query examples can use Snowflake’s built-in Cortex Analyst ([Snowflake Cortex Analyst documentation](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst)).
- **Name overlap:** [Inferred]: The similarly named software studio at axiomat.tech and specification tool at axiomat.dev can cause attribution errors, while the YC profile identifies the startup’s domain as axiomat.com ([AXIOMAT studio](https://axiomat.tech/), [axiomat specification tool](https://axiomat.dev/), [YC company profile](https://www.ycombinator.com/companies/axiomat)).
