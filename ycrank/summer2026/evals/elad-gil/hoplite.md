# Hoplite -- Elad Gil Evaluation

Blueprints processed more than €500K in trading volume from 250-plus users before Ryan Morrissey and Bence Redmond launched Hoplite the following month. Hoplite’s signature is high founder shipping velocity paired with a weak index position: Hoplite looks like fast-iterating founders searching inside a cloud-agent feature set that Cursor, Cognition, and Factory can absorb. That combination can produce a useful product or an acquisition, but it does not yet look like one of the dozen companies that will matter independently ten years from now.

**Perplexity** is the high rung for founder iteration because Aravind Srinivas repeatedly returned a week later with the discussed product built. Hoplite shares the important mechanism: Morrissey and Redmond independently shipped Blueprints, found 250-plus users, processed substantial trading volume, and then rapidly shipped Hoplite rather than defending a stale idea. Hoplite diverges from Perplexity because the dossier documents only one current business installation, no sequence of customer-driven releases, no public repositories for Morrissey, and a three-star top repository for Redmond. Hoplite has demonstrated shipping ability, but not yet the repeated build-feedback-build loop that made Perplexity exceptional.

**Lyft** exposed the low-rung failure mechanism: occupying the number-two position in a market where scale advantages accrue disproportionately to the leader. Hoplite faces a harsher version of that structure because Cursor already exceeds $1B in annualized revenue, Cognition reported $73M ARR, and Factory has raised more than $220M. Devin already hands local CLI sessions to its cloud, while Vercel’s Open Agents commoditizes sandboxes, GitHub integration, and background execution. Hoplite therefore does not yet look like an index on cloud agents; Hoplite must win share against platforms capable of bundling its environment-continuity feature.

Devin 2.2’s computer-use testing, self-verification, and automatic repair provide Hoplite with a credible 2026 catalyst: unattended cloud agents became useful enough that environment migration now matters. Over the next 18 months, longer agent runs should compound demand for credentials, dependencies, MCP servers, and persistent sessions, which helps Hoplite. The same mechanism also increases Cursor’s and Cognition’s incentive to integrate those capabilities directly, so Hoplite is skating for the puck in a recently reopened market without owning the rink. This is a real catalyst, but it is not an overlooked one.

Hoplite’s first business installation reportedly turned ignored Sentry errors into proactive pull requests, while Hoplite’s prepaid credits and free $100 trial show metering rather than actual purchasing velocity. The revenue score would flip into invest territory if Hoplite disclosed named customers compounding above 20% month over month or reached roughly $1M ARR with repeat usage; one unquantified installation remains a promising prototype signal, not “just working” in the Harvey sense. Hoplite does not need Harvey-scale dollars at pre-seed, but Hoplite needs a curve rather than a testimonial.

**Color Genomics** is the relevant single-anchor parallel: the attractive structure is workflow infrastructure placed above a hard capability that has already become available. Hoplite does not need to invent foundation models, cloud sandboxes, or code-generation competence; Hoplite combines validated components into an environment and execution layer. The remaining risks—credential trust, enterprise distribution, and differentiation from Devin—are substantial execution dependencies, but they are not three independent scientific miracles. Hoplite passes the single-miracle test better than it passes the index test.

Devin’s existing local-to-cloud handoff makes my 36-month forecast specific: by July 2029, Hoplite will have pivoted from a general cloud coding agent into secure enterprise agent-environment orchestration and will be acquired by Factory for less than $75M before reaching $10M ARR. Hoplite’s shipping speed should let Hoplite discover the higher-value security and portability problem; its weak distribution position should make selling into a larger agent platform more rational than competing head-on.

Hoplite’s $500K YC financing and one functioning business installation support the strongest opposing case: Hoplite could become the neutral control plane across GitHub, Slack, Linear, CLI, MCP, OpenAI, and Anthropic—the Stripe-like index on every agent rather than another proprietary agent. Mistral shows that platform dependence can be a feature, and Color Genomics shows that workflow above commodity infrastructure can become durable. The objection stings because Morrissey and Redmond have already pivoted and shipped quickly. Devin’s overlapping handoff and Vercel’s open reference stack still win the present evidence, so I would not write the check today. Hoplite reaching $1M ARR while sustaining greater than 20% month-over-month growth for three consecutive months from customers using at least two agent providers would flip that verdict.
