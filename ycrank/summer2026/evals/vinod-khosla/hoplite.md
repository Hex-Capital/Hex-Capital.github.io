# Hoplite -- Vinod Khosla Evaluation

The consequence case is plausible but unquantified. If Hoplite turns ignored Sentry errors and low-priority tickets into continuously merged software, engineering shifts from scarce human execution toward supervised production. That could alter an expensive expert-service pool. But the dossier gives only an $8.51 billion category estimate, not developer hours eliminated, cost per merged change, affected population, or a mechanism for a 10x–100x productivity gain. A large AI market is not itself a large societal consequence.

The product currently looks like orchestration, not a technical discontinuity. Moving local sessions, MCP servers, dependencies, and CLIs into cloud environments addresses real friction, and the first business installation produced proactive pull requests. Yet Cursor already supplies local-to-cloud handoff and reusable environments, while Factory supplies persistent machines and alert-driven workflows. Hoplite presents no benchmark in setup time, task throughput, security, reliability, or cost. iMessage and Sentry triggers are useful features; they are not a Black-Swan mechanism.

The strongest bull case is the founders. Morrissey and Redmond have built together repeatedly, carry relevant Stripe and AWS exposure, and moved from CarbonCopy to Hoplite rather than defending the original product. Their hands-on “Collison” installations may expose workflow details that larger competitors ignore. This resembles the exception where a tiny adaptive team enters an enormous existing value pool with a narrow initial tool, as Block did. The material difference is that Hoplite has not yet shown a proprietary primitive or expansion path that competitors cannot incorporate in one release cycle.

Capital allocation is therefore backward. Manual installations test whether customers appreciate help, but the largest kill risks are feature convergence and secure credential transfer. The dossier supplies no cheapest decisive experiment, numerical threshold, security architecture, budget, or stop condition for either. One installation demonstrates utility, not defensibility. Spending the next dollar on broader distribution before resolving those risks would manufacture activity rather than remove uncertainty.

The economic model is similarly opaque. Prepaid credits may be sensible, but there is no evidence about compute cost, gross margin, utilization, onboarding labor, or whether pricing beats the incumbent combination of cloud infrastructure and existing agent subscriptions. Software does not need a climate subsidy, but it still faces economic gravity: founder-configured installations cannot become a globally cheap software factory unless the installation labor collapses toward zero.

I pass. My 36-month base case is that Hoplite pivots from general cloud-agent deployment into enterprise agent security and environment governance as Cursor and Factory absorb the orchestration features. One result would flip the decision: an independently reproducible pilot showing Hoplite completes representative repository tasks at least 5x faster or cheaper than Cursor and Factory while passing a defined credential-exfiltration test. That would convert this from implementation labor into a technical option worth buying.
